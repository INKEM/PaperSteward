# 常见问题

## 没有模型 key 能用吗？

可以启动和浏览本地已有数据，但生成研究档案与处理论文都需要模型服务。设置页支持本机 loopback 模型（key 可留空），远程服务按厂商要求配置。

## 一定要改 .env 吗？

不需要。普通用户在浏览器 **设置** 页填写 API 地址、密钥和模型名即可，保存后立即生效，无需重启。`.env` / 环境变量只保留给 CLI、容器和自动化等高级场景。

## 保存设置时为什么要勾选同意？

因为论文标题与摘要会发送给你配置的模型服务，用于初始档案生成、分类、概括和评分。保存即授权，替代旧版每次同步的授权勾选；阅读备注始终不发。

## 材料要写多详细？

能说明“研究什么、关注哪些子方向、排除什么、每周读多少”即可。个人主页简介、研究计划、代表性论文摘要都行。材料越具体，生成的研究方向档案与分类标签越贴近你的方向。

## 生成结果不满意怎么办？

直接在意见框用自然语言提要求，再生成一版。页面会显示与上一版的差异；可以反复迭代，满意后确认。确认后档案与分类标签的版本和 hash 会被绑定。

## 能换研究方向吗？

新工作区用新的 `--data-dir` 建立。当前工作区不提供原地重置确认记录的按钮，避免误删已积累的阅读与评分数据。

## 为什么不自动同步、推送邮件？

打开页面只读取本地数据。同步是主动动作，生成日报是独立动作，邮件只通过显式 CLI 发送。需要定时运行的高级用户可配置外部调度，参考[日报指南](advanced/delivery-cli.md)。

## 如何自定义排序？

个人[视图](advanced/views.md)只重排当前合格候选；[全局权重](advanced/config-governance.md)需预览、确认并按生效日启用。特殊桶使用独立档位，不拿它们的档位与主队列分数混排。

## 支持多人或公网部署吗？

当前是单用户本地工具，无登录/鉴权，不面向公网。默认使用本机地址。没有 PDF 全文解析、引文网络或 Zotero/Obsidian/Notion 同步。

## 数据保存在哪里，怎么升级？

Python 在选择的数据目录，Docker 在命名卷。停止服务后保存完整副本，再升级程序；start 或容器 entrypoint 会显式迁移。直接 ASGI 启动不建表。详细见[配置](configuration.md)。

## 能删除或修改归档吗？

冻结归档内容不原地修改；评分和备注的修订追加历史。可导出 BibTeX/CSV/Markdown/JSON，导出可能包含备注，分享前检查。
