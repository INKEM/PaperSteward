# 常见问题

## 没有模型 key 能用吗？

已激活工作区的阅读回顾、手工资产和导出无需模型。可以启动和浏览本地已有数据，但生成研究档案与处理论文都需要模型服务。设置页支持本机 loopback 模型（key 可留空），远程服务按厂商要求配置。

## 一定要改 .env 吗？

不需要。普通用户在浏览器 **设置** 页填写 API 地址、密钥和模型名即可，保存后立即生效，无需重启。`.env` / 环境变量只保留给 CLI、容器和自动化等高级场景。

## 保存设置时为什么要勾选同意？

因为保存后会把数据发送给你配置的模型服务：处理论文时发送标题、摘要及任务所需的研究方向和分类规则，用于初始档案生成、分类、概括和评分；生成草案时发送研究材料、修改意见和上一版草案；自动规划检索式时发送研究档案、已读评分历史和本次关注点。保存即授权，替代旧版每次同步的授权勾选；阅读备注始终不发。

## 材料要写多详细？

能说明“研究什么、关注哪些子方向、排除什么、每周读多少”即可。个人主页简介、研究计划、代表性论文摘要都行。材料越具体，生成的研究方向档案与分类标签越贴近你的方向。

## 生成结果不满意怎么办？

直接在意见框用自然语言提要求，再生成一版。页面会显示与上一版的差异；可以反复迭代，满意后确认。确认后档案与分类标签的版本和 hash 会被绑定。

## 能换研究方向吗？

可以。浏览器顶栏的工作区下拉可新建工作区——每个工作区有独立的论文库、研究档案和阅读队列，切换即换方向，互不影响；不用的旧工作区可在管理页删除（先整目录备份）。只想清空重来时，也可在设置页选择“重置工作区 / 清空数据”：页面会列出清空范围并要求输入确认文字，先保存本地备份，再重新进行首次设置；可选择保留模型连接。高级场景仍可用 `--data-dir` 指定独立数据目录。

## 为什么不自动同步、推送邮件？

打开页面只读取本地数据。用户主动挖掘，论文直接加入长期队列；没有每日定时处理或推送。挖掘不需要手填检索词：Agent 依据研究档案与已读评分历史自动生成检索式，运行报告里可以查看每条检索式与理由。日报与邮件 CLI 作为高级遗留功能保留，参考[遗留日报指南](advanced/delivery-cli.md)。

## 如何自定义排序？

个人[视图](advanced/views.md)只重排当前合格候选；[全局权重](advanced/config-governance.md)需预览、确认并按生效日启用。特殊桶使用独立档位，不拿它们的档位与主队列分数混排。

## 支持多人或公网部署吗？

当前是单用户本地工具，无登录/鉴权，不面向公网。默认使用本机地址。没有 PDF 全文解析、引文网络或 Zotero/Obsidian/Notion 同步。

## 系统外读过的论文怎么入库？

在「归档」页点 **导入已读论文**：粘贴 DOI、arXiv ID 或论文链接（留空则手动填写），确认元数据并给出 1–5 评分后直接进入归档，带「导入」标记。导入的论文不会再被挖掘重复处理，评分参与阅读偏好画像与挖掘规划。注意：一次导入大量同一主标签的论文，会在接下来几周内降低该标签的挖掘补给——这是「读过就不必再挖」的预期行为；导入时不选标签则不参与补给节奏。

## 导入时解析失败怎么办？

解析只作用于预填：连不上来源或查不到记录时，会直接进入手动填写表单并提示，补全标题等信息即可完成导入，不会因为外部服务失败而卡住。重复导入已在库中的论文会被拦截，并给出详情页链接，到详情页修订评分与备注即可。

## 数据保存在哪里，怎么升级？

Python 在选择的数据目录，Docker 在命名卷。停止服务后保存完整副本，再升级程序；start 或容器 entrypoint 会显式迁移。直接 ASGI 启动不建表。详细见[配置](configuration.md)。

## 能删除或修改归档吗？

冻结归档内容不原地修改；评分和备注的修订追加历史。可导出 BibTeX/CSV/Markdown/JSON，导出可能包含备注，分享前检查。

## 名次、评分与运行进度怎么看？

队列中的“第 N 名”是当前筛选列表的名次，“综合评分”是 0–100 分的推荐参考。排序使用平滑后的分值，和综合分可能略有不同。详情页展示研究相关性、可信度线索、复用价值、新鲜度、方向平衡和阅读偏好，并给出可用的原文依据。长期未刷新时显示快照日期，可点“刷新排序”在本地计算，不调用模型。

顶部显示当前任务、当前论文、处理篇数和用时，每 2 秒更新；结束后自动刷新。低置信度与摘要质量问题只记录质量标记；完全无摘要的论文跳过。队列没有每日配额，不读的论文继续保留，无需延期或跳过。

## 首次设置确认后，还能看研究档案吗？

能。“设置”和“首次设置”页面都展示已确认的研究档案与分类标签，包括子方向、关键词、纳入/排除规则和阅读建议；也可展开 Markdown 源码核对。

## 补录 50 篇旧论文，为什么本周只读了 2 篇？

补录表示论文何时进入归档，阅读量表示实际阅读发生的周期。两者可能重叠，不能相加。导入不填阅读日期时为未知，只进入全部历史和未定日期库存；只记得月份会计入整月回顾，周回顾不伪造阅读日。

## 旧报告为什么没有最新评分或补记日期？

报告是冻结快照。“当时记录”的历史周期只使用周期结束前已记录的内容，今天的修订不会倒灌。“现在重新回顾”按本次采集截止纳入后补、更正。详情的变化提示按原时区、模式和周期比较有效事实，周期外无关的新阅读不使旧报告失效；全库库存数字单独变化也不会被当作该周期的事实变化。需要新内容时主动重新保存，原报告和导出保留原样。

专题变化提示还沿用原主标签与分类版本，范围外反馈、资产修订不会制造新版本。资产按活动发生时的来源版本归属，跨主题资产计一次；报告只引用本范围内的版本。仅库存变化时重复保存会沿用旧快照，因而快照中的库存数字和截止时间也保留原值。

同系列要求周期、主题及分类版本、时区、模式、统计口径和是否保存资产正文一致，系列内支持分页。新报告的范围独立保存，清理运行记录不会丢失；旧报告中无法证实的主题或统计算法标为未知，继续保留正文和导出，但不猜测系列或判断变化。需要比较时选择明确范围重新保存。

## 阅读回顾需要模型吗，会改推荐吗？

已完成首次设置的工作区可离线使用事实概览、保存报告、手工资产和导出，无需模型配置。事实版回顾不会联网；单篇阅读分析与知识版回顾只在对应用途单独授权后调用模型，且只使用预览中列出的材料。第二阶段的知识资产整理已可用，长期画像候选与第三阶段推荐反哺尚未上线。

## 怎样导出、删除收获和问题？

阅读回顾中的“导出副本”默认提供不含私人原文的事实分享副本；知识版报告还会整条排除依赖私人材料（备注、结构化理由、摘录、资产内容、已核对候选）的归纳，并显示涉及的类别。个人完整 JSON 副本须显式确认，含全部资产修订、来源和反馈备注，仅供本地保存，当前没有自动导入恢复入口。报告个人副本来自保存快照。删除资产会预览各版本、来源和含私人正文或私人归纳的报告，可以勾选一并删除报告；未勾选的正文副本、已下载文件和备份仍然存在。仅引用资产的旧报告显示“来源已移除”。

资产修订只改标题、正文等内容时不影响来源：未主动增删的来源连同其引用的具体反馈版本原样保留；表单中的来源列表每行一篇论文，删除行即移除该来源，新增行按未引用反馈处理。历史版本可从资产详情的「历史版本」逐版打开，查看当时的正文、适用说明与来源（含反馈评分与归档哈希）；引用的反馈已不存在时会明确说明。

删除资产时，预览会列出全部含此资产私人副本的报告（标明含标题还是正文），可勾选一并删除整份报告；未勾选的报告保留原副本，可在该报告中删除整份或「另存脱敏版本」——脱敏版本是新建的报告快照，清除资产标题与正文副本，原报告与其哈希保持不变，重复另存沿用同一份。系统同时登记「哪份资产的标题/正文进入过哪份报告」，资产删除后仍能定位残留副本；已下载的导出文件与数据库备份不会自动收回，需要自行保管或删除。

## 阅读分析会自动把备注发给模型吗？

不会。阅读分析默认关闭：即使在设置页连接并同意过模型，只要没有在「阅读分析」页为该用途单独授权，分析对模型的调用次数为零——授权独立于模型连接的知情同意。授权时逐类勾选允许发送的材料（冻结元数据、历史模型概括、评分、结构化理由、备注、资产内容、用户摘录），备注等私人文本只有在显式勾选后才进入分析；每次授权绑定当时的端点与配置版本，任何模型设置保存都会使旧授权失效，需要重新核对数据去向再授权。「阅读分析」页的材料清单预览只读本地数据库、不联网，能看到将发送哪几篇、哪些版本锚点和类别；预览令牌 15 分钟有效且只能用于一次提交。撤回授权立即停止新的发送。

## 知识版回顾和事实版报告有什么区别？

事实版报告只做确定性统计（本期阅读、补录、评分分布、反馈修订、资产整理活动），不调用模型，任何时候都能生成。知识版回顾在同样的事实之上，用你单独授权发送的材料请模型整理少量「专题（问题—方法—场景的条件对照）/ 仍未解决的问题 / 候选联系」，并披露实际用了多少材料、哪些论文缺失、哪些因预算省略、哪些来源引用被服务端拒绝；材料不足或部分失败时不会把结果说成完整专题。知识版报告是 `reading-insights.report/2`，事实版是 `/1`，应用会按保存时的契约读取：旧报告继续可读、可导出、可同系列比较，未知版本会明确报错而不是猜成新格式。知识整理是模型归纳、待你核对，不会自动写入资产或长期画像；未生成周报也能直接生成月报。

知识版回顾使用独立的「跨文献专题综合」授权，与单篇阅读分析分开。默认材料类别只有冻结元数据与历史模型概括；备注、结构化理由、摘录、资产内容和已核对候选都要显式勾选并单独授权。模型设置（地址、密钥、模型名、超时）的任何保存都会使旧授权失效，发送前与保存前会再次核对。分享副本默认整条排除依赖私人材料的归纳；个人副本需在导出页勾选原文说明，并会列出涉及的材料类别。

## 分析候选可信吗，会自动改我的资产吗？

不会自动改。候选只是模型基于你获准发送的材料给出的整理建议，每条都标注结论性质：论文陈述（引文逐字核对过）、用户表达（来自你的备注/理由/摘录）、模型归纳（待核对）。候选未经你确认不会写入任何资产或长期画像；伪造来源或不在材料中的引文会被服务端证据核对逐条剔除。分析运行有预算与取消边界：单次最多 200 篇、输入超限在篇目边界停止（不静默截断），取消保留已完成篇目，重启后用原参数重试会自动跳过已有候选的篇目。

候选在「核对候选」页处理：**确认**生成资产（可选类型为收获/问题/方法卡/证据组，来源默认引用候选论文，可修改）——确认表示你认可这条个人整理，不等于系统验证论文真实性；**并入**把候选内容追加为已有资产的新版本（保留其来源，原引用不变）；**忽略**记录这条候选不采用。每条候选只能处理一次，重复提交返回同一结果。被忽略的候选按（论文、类型、陈述）记忆：再次分析产出完全相同陈述不再弹出，改写后的新候选仍会展示。方法卡与证据组是新的资产类型，结构化字段（问题/关键做法/限制；论点/支持材料/尚未核实）与自由正文分列保存。

## 结构化理由是什么，必须填吗？

不必须。原评分＋备注照常直接归档，结构化理由完全可选：在归档详情的「结构化理由（可选）」折叠表单里，用少量选项说明这篇的价值来源（方法可复用、帮助理解、改变认识、提供论据、带来研究想法、可用于当前任务）或价值有限的原因（当前任务不适合、内容已知、证据存疑、适用条件不满足、暂时看不懂），可选填任务／专题说明、阶段性适用范围和一句收获、疑问或实际使用结果。自由文本属私人材料，只保存在本地；回顾报告与概览只记录理由码和有无标记，不发送、不导出原文。理由可反复修订，可关联到具体某次的评分（之后改评分不会把旧理由解释成新评分的原因）；「清除全部理由」保留修订历史。事实统计只数显式填写的维度，空理由不会补成中立，也不会从评分推导任何维度。

## 阅读回顾如何备份与恢复？

重置工作区前自动备份完整数据库，日期修订、报告、资产各版本及来源都在其中，清空时一并清除。恢复前停止服务，先备份现有数据库及配套的 `-wal`／`-shm` 文件，再将 `backups/before-reset-….db` 复制回该工作区原数据库位置，清除旧数据库配套的 `-wal`／`-shm` 文件后重启；不要在运行时替换数据库。删除非默认工作区保存的是完整目录 `backups/deleted-…-w-…/`，停服后移回 `workspaces/w-…/`，下次启动会重新登记（名称可能显示为工作区 ID）。备份含私人内容和模型配置，请保管好。

从迁移 0031 回退到 0030 会删除跨文献专题综合授权与知识版报告的私人归纳登记；存在综合授权或综合登记时会明确拒绝，请先撤回授权或导出/删除相关报告再降级。从迁移 0027 回退到 0026 会删除全部结构化理由历史及其写入回执（不可恢复，降级前先备份），其余数据不受影响。从迁移 0026 回退到 0025 只删除私人派生副本登记（可再次升级时从报告重新回填）。从迁移 0025 回退到 0024 只删除写入回执（保存请求的去重记录）：阅读日期与资产创建的请求ID仍在原数据列上，再次升级会自动回填；修订／状态的回执不可恢复，此后重复提交会按版本冲突提示而不是重放原结果。从 0024 回退到 0023 只删除报告范围上下文和有效输入清单，冻结报告、日期、资产仍保留；再次升级只能恢复有证据的旧参数，运行记录已删除时无法重建原范围，显示未知。从 0023 回退到 0020 会删除阅读日期声明、全部报告、手工资产版本及来源，原归档和反馈仍在。数据库回滚前先做完整备份；关闭页面入口不会撤销迁移。
