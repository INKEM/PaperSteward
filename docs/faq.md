# 常见问题

## 没有模型 key 能用吗？

可以离线体验全部首启向导与合成试运行日报，并浏览本地已有内容。真实论文处理需要兼容模型；本机 loopback 模型可不填 key，远程模型按服务要求配置。

## 示例指标通过代表效果好吗？

不代表。示例标注和分数固定，只验证界面、校验与确认流程。正式使用需自己的研究方向、分类种子、双方独立校准和试运行反馈。

## 十分钟内能看到什么？

安装完成后，用 Starter 完成设置并看到合成试运行日报。下载依赖、构建镜像和真实模型处理耗时不固定，不能承诺真实论文质量或固定处理时长。

## 为什么不自动同步、推送邮件？

打开页面只读取本地数据。同步需要主动勾选授权，生成日报是独立动作，邮件只通过显式 CLI 发送。需要定时运行的高级用户可配置外部调度，参考[日报指南](advanced/delivery-cli.md)。

## 已经确认离线，后来想换成真实研究怎么办？

停止服务，用新的 `--data-dir` 建立工作区，在 G4 明确数据范围。既有确认记录不可原地改写；没有重置数据库按钮。

## 如何自定义排序？

个人[视图](advanced/views.md)只重排当前合格候选；[全局权重](advanced/config-governance.md)需预览、确认并按生效日启用。特殊桶使用独立档位，不拿它们的档位与主队列分数混排。

## 支持多人或公网部署吗？

当前是单用户本地工具，无登录/鉴权，不面向公网。默认使用本机地址。没有 PDF 全文解析、引文网络或 Zotero/Obsidian/Notion 同步。

## 数据保存在哪里，怎么升级？

Python 在选择的数据目录，Docker 在命名卷。停止服务后保存完整副本，再升级程序；start 或容器 entrypoint 会显式迁移。直接 ASGI 启动不建表。详细见[配置](configuration.md)。

## 能删除或修改归档吗？

冻结归档内容不原地修改；评分和备注的修订追加历史。可导出 BibTeX/CSV/Markdown/JSON，导出可能包含备注，分享前检查。
