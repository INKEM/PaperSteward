# ADR 0004：独立校准轮次、盲标与 G3

- 状态：采纳（2026-10-21，P2-S4）。
- G2 种子清单通过 Paper 仓储幂等导入，只新增 discovered 元数据，不覆盖同 ID 的
  不同内容。校准 cohort 使用与 G2 种子 ID 不重合的 15–20 篇留出样本；不把已知
  种子标签复制为校准结果，不写 Rating、PaperTag、ScoreSnapshot 或归档。
- 新增 onboarding_calibration 表与可逆迁移 0004：两轮上限、固定 G2/档案/分类法
  绑定、不可变 cohort、两方独立标注及报告。追加事件记录创建、提交与报告；不使用
  Config/Rating 混存不同量纲的数据。无新增依赖，现有 P1 表字段保持不变。
- Agent/用户分别完整提交，单方提交不可覆盖；双方完成前 API 只返回可标注元数据
  和提交状态，隐藏参考标签、抽样分层和另一方标注。无多用户鉴权，不声称提供身份隔离。
- cohort 约 60/20/20 分层（各与目标数相差至多 1）、覆盖全部主标签、至少 3 个含两个
  有效标签的边界案例、2–3 个看似相关的偏好负例。metadata 为人工/fixture 的策展依据。
- Spearman 用平均并列秩的 Pearson 相关，常数向量返回 null；Top-5 用分数降序、ID
  升序破并列。标准库足够，避免引入 SciPy 的体积/额外依赖面。分类/阅读方式一致率、
  边界争议与方向/rubric 建议仅诊断，不擅自改变权重。
- 达标为 Spearman ≥0.6 且 Top-5 重合 ≥3；依据设计 §4.5，任一指标未达标可由用户
  明确接受并填写非空已知偏差。不能豁免样本结构/完整标注/版本绑定。只允许确认最新轮，
  最多两轮；需要修改已选档案/分类法时先走再协商，不静默换版本。
- 同一事务写入标注/报告/事件，G3 保存审阅报告与接受偏差快照。合成 cohort 或
  合成 G2 依据一律标记“仅流程验证”。不接真实来源/LLM，不提前实现试运行或 G4。
- 回滚：downgrade 0003 只删除新表，导入的 Paper 与审计事件保留；完整撤销数据或运行
  旧事件枚举代码时，停止应用并恢复 S4 前备份。不得据降级假定 G3 自动撤回。
