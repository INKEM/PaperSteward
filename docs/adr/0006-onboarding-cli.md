# ADR 0006：本地 onboarding CLI 与已审快照

- 状态：采纳（2026-10-22，P2-S6）。
- 按计划 CLI/API 优先，以最小 CLI 完成初始化体验。使用标准库 urllib 连接现有
  本地 API；不新增运行时 HTTP/模板依赖、不复制业务服务，不添加任意门禁放行入口。
- 提交/两方标注/反馈为独立命令；不生成用户答案。全文/差异/参数/报告可读展示，
  --json 支持脚本；所有演示数据都说明仅流程验证。
- review/submit 的 --out 保存包含服务器、阶段、revision、类型、完整响应的 JSON
  审阅快照及 SHA256 校验和。快照不覆盖文件，权限 0600；校验和用于发现意外编辑，
  不是签名或鉴权。confirm 必须携带 --gate/--by/--summary/--yes，使用该快照原始
  hash/revision，不自动 GET 新依据。已变更/跨服务器/错误类型快照不用于确认。
- loopback URL、不使用代理/重定向、固定超时、不自动重试 POST；防止用户档案被
  意外转发。CLI 不读服务器 .env、不建表/迁移。错误提示不回显请求或秘密配置。
- 本地文件保存失败时明确服务端操作可能已经完成，提示用 review 恢复，不能重试
  POST 造成重复版本。可预见的文件冲突在请求前拒绝。
- 无 schema 变更；回退 CLI 代码不撤销已经确认的文档/配置/门禁。要撤销初始化须
  停止应用并恢复操作前备份；当前不提供 reset 或再初始化入口。
