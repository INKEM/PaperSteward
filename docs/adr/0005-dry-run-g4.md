# ADR 0005：版本化试运行日报、反馈与 G4

- 状态：采纳（2026-10-21，P2-S5）。
- 试运行只接收预选合成 fixture，保持输入顺序；验证配额/相关度/标签，不在 P2
  实现生产排序、评分、特殊桶、发送或调度。全部报告标注“仅流程验证”。
- 运行参数显式包含时间/时区、安静时段、暂停、主标签目标占比、渠道和模型数据范围；
  配额和权重复用 P1 ScoringConfig。目标占比覆盖当前全部主标签且和为 1，不静默
  归一化；安静时段不得包含推送时间。渠道仅 local_markdown；备注不外发。
- 复用 append-only Event 保存输入、递增整数版本、绑定、完整报告/Markdown/hash
  及反馈历史；无新表/迁移/依赖。该记录是独立审阅产物，不混入生产分数/归档。
- G3 精确报告及其上游文档须保持一致；G4 只接受最新日报、该版本最新的明确认可
  反馈和显式确认（双 hash + revision）。负面反馈保留，不激活；用户可追加新参数
  版本，或明确重新审阅同版并认可。认可反馈不得同时带未解决问题。
- G4 才提交 scoring 与 onboarding_runtime Config；已有同版本 scoring 必须完全
  相等，避免覆盖用户配置或在预览时改变 current。运行配置版本使用日报整数版本。
  配置、事件、门禁同事务落地；失败整体回滚。
- 认可参数仅是后续功能的输入：ACTIVE 不会创建发送任务或启用真实模型；未来
  发送器还需遵守暂停/安静时段/渠道/隐私等规则。无鉴权/身份隔离。
- 日报按纯文本转义不可信字段，不执行论文中的指令；无 HTML/模板执行。
- 回滚：无 schema 变更。完整撤回激活/回旧事件枚举代码须停应用并恢复 S5 前备份；
  仅回退代码不会撤销 Config 或 ACTIVE，不得降级迁移/手改状态冒充回滚。
