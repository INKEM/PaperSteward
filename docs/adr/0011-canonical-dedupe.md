# ADR 0011：离线 canonicalization 与去重

- 采用，2026-10-22，P3-S6，无依赖/迁移。
- 依次匹配规范化 DOI、无版本 arXiv ID、标题、作者/年份/venue、摘要近似。
  DOI 去前缀/URL解码/小写；arXiv 去URL/pdf/版本；标题 NFKC、casefold、去标点。
  强标识相冲突时禁止弱匹配；共享 arXiv 可合并预印本与正式版的不同 DOI。
- 标题长文本精确相同可合并；模糊≥0.94需作者交集。作者/年份/venue同时相同仍
  必须有标题词集合重叠≥0.7且字符相似≥0.65，不仅凭同作者同年合并。
- 未引入 embedding/真实模型：摘要使用5词shingle Jaccard≥0.95、至少30词，
  作者双方已知时必须有交集。此为可复现词法近似，不能声称语义相似度>0.95已实现；
  对改写/翻译可能漏检，作为已知召回边界。拒绝短/模板化摘要近似合并。
- 匹配后归并连通分组，记录每次匹配原因；排序固定，不随输入顺序变化。共享强ID
  桥接可连接此前两组。正式版元数据优先、最早公开日期保留、摘要优先最早有摘要版本。
  所有来源provenance保留；规范化不修改raw metadata。文献类型统一常见别名。
- canonical ID 为 DOI/arXiv/标题作者年份的 SHA256 截断，P3-S7 需先查现有记录与来源
  指纹再分配库内ID，不能因新增DOI把旧记录重建成新文献。
- 只做纯转换，不写库/更改状态/评分。大批量采用O(n²)保守匹配，S7必须限制单次候选量；
  大规模索引优化不在本阶段。回滚代码即可，DB head0004。
