# 排障

先看启动错误或网页运行详情。密钥不要粘贴到 issue；未知错误返回通用信息，详细日志在本地。`papersteward doctor` 只诊断，不迁移；记得使用与 start 相同的数据目录配置。

| 现象 | 下一步 |
|---|---|
| 端口被占用 | 停止旧服务，或 `papersteward start --port 8001`；Docker 修改本地端口映射 |
| 数据目录不可写 | 选择自己可写的目录，检查目录权限和磁盘空间 |
| 迁移失败/落后 | 停服务保存完整数据副本，检查安装版本，再运行 start；直接 ASGI 用户需显式 Alembic 升级 |
| 安装后找不到命令 | 虚拟环境用 `.venv/bin/papersteward`；pipx 按其提示配置 PATH 或使用其 bin 完整路径 |
| 页面没自动打开 | 手动访问127.0.0.1:端口/ui/setup；无桌面环境可加 --no-browser |
| 确认冲突、hash或revision不匹配 | 返回当前步骤重新打开最新报告审阅，重新确认；不要篡改隐藏字段 |
| JSON/文档校验失败 | 检查错误字段、版本、标签与种子格式；文件最多256KiB，整份表单最多512KiB |
| 提示未完成初始化 | 按 G1→G4 顺序确认；保存草稿、生成报告不等于确认 |
| 提示未授权模型数据 | 离线工作区按其确认范围运行；正式使用在新工作区确认自己的资料与数据授权 |
| 模型缺配置/认证失败 | 检查 provider、API根地址、模型名及 key；见[模型指南](llm-provider.md) |
| Docker 模型配置不生效 | 修改根目录.env后重建/重新创建服务；检查 Compose 显式传入的字段，勿输出带密钥的完整配置 |
| 同步来源失败/限流 | 检查检索词和来源，等待后在运行页显式重试；已采集数据保留 |
| 处理后仍无日报 | 先处理审核，查看队列合格条件；低相关/特殊桶/缺摘要/版本不匹配不会进入主队列 |
| 暂停/安静时段拒绝 | 核对已确认运行参数；阅读与查看历史仍可用 |
| 运行中关闭页面 | 从今日页进入最近运行查看；重启造成中断会标记失败，检查后重试 |
| 生成时报无合格候选 | 先同步、处理、审核；网页不会保存空的不可变日报 |
| 日报没因新增论文改变 | 同一天日报不可变，新增候选通常进入下一份日报 |
| 邮件送达不确定 | 人工核对收件箱/服务商记录，勿删记录、降迁移或绕过幂等重发 |

重试会创建新 Run，原失败记录保留。相同 Run ID 和相同输入只执行一次，换输入复用 ID 会冲突。普通审核不能代替特殊桶确认；对应待审项在审核页分别显示。

回滚代码不会撤销已写入的数据；需要恢复旧状态时使用操作前完整副本。不要直接修改 SQLite 状态绕过门禁。
