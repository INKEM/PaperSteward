# 排障

先看启动错误或网页运行详情。密钥不要粘贴到 issue；未知错误返回通用信息，详细日志在本地。`papersteward doctor` 只诊断，不迁移；记得使用与 start 相同的数据目录配置。

| 现象 | 下一步 |
|---|---|
| 端口被占用 | 停止旧服务，或 `papersteward start --port 8001`；Docker 修改本地端口映射 |
| 数据目录不可写 | 选择自己可写的目录，检查目录权限和磁盘空间 |
| 迁移失败/落后 | 停服务保存完整数据副本，检查安装版本，再运行 start；直接 ASGI 用户需显式 Alembic 升级 |
| 安装后找不到命令 | 虚拟环境用 `.venv/bin/papersteward`；pipx 按其提示配置 PATH 或使用其 bin 完整路径 |
| 页面没自动打开 | 手动访问 `127.0.0.1:端口/ui/setup`；无桌面环境可加 `--no-browser` |
| 设置页提示未配置模型 | 填 API 根地址、密钥与模型名并保存；本机模型可留空密钥；见[模型指南](llm-provider.md) |
| 测试连接失败 | 检查 API 根地址是否多写了 `/chat/completions`、密钥是否有效、本机 HTTP 是否仅用 loopback |
| 同步时报 `LLM 认证失败` | 设置页保存的配置没有密钥或密钥无效；填入密钥并点「测试连接」验证。旧 `.env` 中同 origin 的密钥会被自动沿用 |
| 生成草案长时间无进展 | 到运行页查看状态；模型超时/限流会显示原因，可回设置页增大超时后重试 |
| 生成草案报 schema 字段错误 | 模型输出未通过校验且自动修复失败；运行页会显示具体字段，可重试或换模型 |
| 确认冲突、hash 或 revision 不匹配 | 返回首次设置页重新打开最新草案审阅，再确认；不要篡改隐藏字段 |
| 材料过大 | 单份表单上限 512 KiB；合并后超长会自动截断并提示，拆成多份或删减后重试 |
| 提示未完成初始化 | 先连接模型、生成并确认草案；保存材料或生成草案不等于确认 |
| 同步被拒 | 确认当前工作区已完成初始化；检查运行页错误与是否有其他任务正在运行 |
| 同步来源失败/限流 | 换个来源或稍后在运行页显式重试；已采集数据保留，检索式由 Agent 每轮自动更换 |
| 挖掘后队列为空 | 查看运行摘要与队列合格条件；低相关/特殊桶/缺摘要/版本不匹配不会进入主队列；保底填充会在下限内补足并标注 |
| 提示已有任务运行或返回 409 | 队列顶部或运行页查看当前任务，完成后再开始新任务；不会静默排队 |
| 超过 5 分钟无更新 | 检查来源、模型连接和本地服务日志；可能仍在等待请求超时。失败后用相同参数显式重试 |
| 运行中关闭页面 | 从阅读队列页进入最近运行查看；重启造成中断会标记失败，检查后重试 |
| 暂无合格候选 | 挖掘仍算成功；下一轮 Agent 会自动换角度生成检索式；也可换来源、或填一句「本次关注点」引导 |
| 同一天新挖掘的论文没有出现 | 刷新队列筛选条件，并查看任务是否完成“刷新队列”阶段；新流程不依赖日报 |
| 排序日期较旧 | 点击刷新排序；同一天已有快照复用，次日会重新计算 |
| 想重新测试首次设置 | 设置 → 重置工作区 / 清空数据；确认后自动备份再清空，可保留模型连接 |
| 旧工作区升级后提示模型未授权 | 到设置页保存一次模型配置；旧 `.env` 配置只作为回退，不自动获得网页授权 |
| 导入论文时解析失败 | 解析只用于预填：直接在手动填写表单补全标题等信息完成导入，外部来源失败不会卡住流程 |
| 导入提示「该论文已归档/已在库中」 | 这篇论文已在库里：按提示打开详情页修订评分与备注即可，重复导入会被拦截 |
| 导入后同类论文挖掘变少 | 预期行为：导入评分参与挖掘规划，同主标签批量导入会在几周内压低该标签的挖掘补给；导入时不选标签则不参与 |
| 邮件送达不确定 | 人工核对收件箱/服务商记录，勿删记录、降迁移或绕过幂等重发 |

重试会创建新 Run，原失败记录保留。相同 Run ID 和相同输入只执行一次，换输入复用 ID 会冲突。低置信度分类与摘要质量问题仅记录质量标记；没有摘要文本的论文会跳过。特殊桶仅自动接受有效且置信度不低于 0.8 的提名，其余留在主队列。

回滚代码不会撤销已写入的数据；需要恢复旧状态时使用操作前完整副本。不要直接修改 SQLite 状态绕过初始化检查。

## 阅读回顾

| 现象 | 处理 |
|---|---|
| 导入后阅读量没增加 | 导入时间与阅读时间独立；在归档详情补记日或月份。未知日期在全部历史中保留，月精度不计入某个精确周 |
| 历史周报看不到后来补录、更正 | 默认“当时记录”使用历史截止；切换“现在重新回顾”后主动保存新版本，旧快照保持不变 |
| 旧报告显示主题或统计口径未知 | 历史参数不足以可靠恢复范围；原正文与导出可继续使用。选择明确主题、周期和模式重新保存，不把未知范围当全部主题 |
| 两份报告无法比较 | 选择同系列中的版本；周期、主题及分类版本、时区、模式、统计口径或正文副本选项不一致时不支持比较 |
| 专题资产显示的版本不是最新版本 | 专题按活动发生时的来源选择版本；后来转入其他主题不会改写本范围的历史。跨主题来源至少一篇匹配时计一次 |
| 没有可回顾记录或筛选无结果 | 回到归档完成阅读／导入，或清除主题筛选；未完成首次设置会引导到初始化页，不自动生成研究档案 |
| 保存回顾时提示任务占用 | 打开提示中的现有运行，完成或停止后再提交；工作区内与挖掘、草案提取共享一个任务位 |
| 停止或重启后没有新报告 | 停止在读取批次边界生效，未完成的报告不保存；重启后的未完成任务标为失败，可用原参数重试，已有报告可继续打开 |
| 编辑资产提示其他页面已更新 | 草稿保留在表单中；核对最新版本后再保存，避免覆盖另一窗口的修改。提交失败不消耗表单的请求ID，修正后直接重试即可 |
| 结构化理由提示其他页面已更新 | 表单自动展开并保留已填内容；版本号已刷新，核对后直接重试即可，同一请求ID不会因此作废 |
| 想撤掉已保存的结构化理由 | 在同一表单点「清除全部理由」：生成一条空记录，历史修订保留，事实统计立即按空理由计（不补成中立）；理由历史随数据库备份保留 |
| 关联的评分版本不存在 | 理由关联的是具体某次评分；提示时刷新页面重新选择下拉项再保存，此时幂等键未被消耗，可直接重试 |
| 重试保存资产却提示「请求ID已用于不同操作」 | 同一请求ID只能对应同一次提交；刷新页面拿到新表单（新请求ID）后再改。保存成功但响应丢失时，原样重试会返回当初的结果，不会产生重复版本 |
| 资产修订后来源少了反馈引用 | 只有在表单中删除该来源行、或通过 JSON 接口显式替换来源时才会去掉引用；只改文本不会动来源。可在历史版本中核对当时的来源与反馈 |
| 个人副本无法下载 | 返回导出页勾选私人原文说明；全部历史的个人完整副本选择 JSON，Markdown 用于事实或报告副本 |
| 删除资产后报告仍有正文或标题 | 删除范围预览列出全部含私人副本（标题/正文）的报告，可勾选一并删除；不勾选的报告保留原副本，可在该报告中删除整份或「另存脱敏版本」。原有下载与备份须自行处理 |
| 报告里有「（私人标题已移除）」 | 这是另存的脱敏版本：资产标题与正文副本已被清除，原报告保持不变；页面顶部标注了原报告链接 |
| 阅读分析授权突然失效 | 模型连接的任何保存（地址、密钥、模型名、超时）都会产生新配置版本并使既有授权失效，这是设计行为：重新核对数据去向与类别后再次授权即可 |
| 预览令牌被拒绝 | 令牌 15 分钟有效、只能用于一次提交，且绑定当时的模型配置；重新生成预览后再提交 |
| 分析运行失败提示授权失效 | 每篇发送前都会重新核对授权与模型配置版本；运行中修改模型设置会停止后续发送（已完成篇目保留），重新授权后用原参数重试即可 |
| 分析结果区没有候选 | 可能是材料不足（合法结果）、候选全部被证据核对剔除（伪引文/越界来源）、源版本漂移被跳过，或预算/取消导致未运行到该篇；运行行会显示各计数明细 |
| 个别论文分析失败 | 单篇失败不影响其他篇目；失败原因见运行页（不含技术细节），用原参数重试会自动跳过已完成篇目 |
| 候选页提示「该候选已处理」 | 每条候选只能处理一次且决定不覆盖：已确认/已并入的候选可直接修订对应资产，已忽略的候选表示不再采用；打开提示中的资产查看 |
| 忽略的候选又出现了 | 只有完全相同的（论文、类型、陈述）会被记忆过滤；改写后的新候选或新证据产生的新候选仍会展示——这是设计行为 |
| 想恢复重置或误删工作区的数据 | 先停止服务并保留当前副本，再按 [FAQ 的恢复步骤](faq.md#阅读回顾如何备份与恢复) 恢复完整数据库／目录；个人 JSON 导出目前没有自动导入入口 |
| 知识版回顾提示未授权／授权失效 | 与单篇阅读分析分开授权；模型连接的任何保存都会使旧授权失效。回到「知识版回顾」页核对类别后重新授权，未授权时不会发送 |
| 知识版回顾说材料不足／覆盖不完整 | 可能是所选类别在该范围没有材料、源版本已过期、论文缺失或超出预算；预览与报告会列出缺失/过期/省略计数。调整范围或类别后重新预览，不要把部分结果当完整专题 |
| 分享副本里少了某条专题或问题 | 该条依赖私人材料（备注/理由/摘录/资产内容/已核对候选），分享副本按来源链整条排除；打开导出页查看涉及类别，个人副本需显式勾选说明 |
| 资产删除预览出现不认识的知识版报告 | 报告的综合归纳引用了该资产作为私人来源；可勾选一并删除报告，或在该报告「另存脱敏版本」保留公开条目 |
| 知识版报告提示未知契约版本 | 报告由更新版本的应用保存，当前版本不认识该契约；先升级应用再打开，不要按旧格式猜测解析。旧 `/1` 事实报告不受影响 |
| 降级数据库时提示无法回退 0031 | 当前库存在跨文献专题综合授权或私人归纳登记；先撤回授权并导出/删除知识版报告，或保留完整备份后再处理 |


## 研究记忆

| 现象 | 处理方法 |
|---|---|
| 有很多旧阅读，却只显示兴趣线索 | 稳定价值标准检查的是不同论文的真实反馈形成时间，至少 3 篇并跨 2 个自然月；阅读日期回溯声明、集中补录或同一项目不会变成长期偏好 |
| 没有长期价值候选 | 需要明确的结构化价值理由，评分高低不能替代理由；可在原论文中自愿记录理由，并在预览中选择和授权该类别，不需要为了生成画像补写旧反馈 |
| 改写后旧预览无法提交／任务失败 | 用户决定已更新，旧清单不能覆盖修正；重新预览。已保存措辞和停用决定会继续保留 |
| 本次授权后无法再提交另一份清单 | 本次授权只覆盖原预览清单；使用授权后页面保留的提交按钮，换清单需重新授权，或明确选择持续授权 |
| 源版本缺失、授权撤回或材料超过预算 | 不发送变化后的材料、不静默截断；排除无效／过长材料后重新预览。已有条目可在详情核对来源问题并删除全部本地版本 |
| 删除资产后研究记忆仍在 | 删除预览列出相关画像；删除来源只追加需复核记录并停止使用，不偷偷删除用户措辞。若要删除私人画像副本，到对应条目选择删除全部版本 |
| 停用后重新分析仍能看到旧条目 | 停用历史保留便于回看，但不会重新生成或被用于推荐。要清除本地副本，请在条目页核对后删除全部版本 |
