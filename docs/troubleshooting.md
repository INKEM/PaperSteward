# 排障

先看启动错误或网页运行详情。密钥不要粘贴到 issue；未知错误返回通用信息，详细日志在本地。`papersteward doctor` 只诊断，不迁移；记得使用与 start 相同的数据目录配置。

| 现象 | 下一步 |
|---|---|
| 端口被占用 | 停止旧服务，或 `papersteward start --port 8001`；Docker 修改本地端口映射 |
| 数据目录不可写 | 选择自己可写的目录，检查目录权限和磁盘空间 |
| 迁移失败/落后 | 停服务保存完整数据副本，检查安装版本，再运行 start；直接 ASGI 用户需显式 Alembic 升级 |
| 安装后找不到命令 | 虚拟环境用 `.venv/bin/papersteward`；pipx 按其提示配置 PATH 或使用其 bin 完整路径 |
| 页面没自动打开 | 手动访问 `127.0.0.1:端口/ui/setup`；无桌面环境可加 `--no-browser` |
| 设置页提示未配置模型 | 填 API 根地址、密钥与模型名并保存；本机模型可留空密钥；见[模型指南](llm-provider.md) |
| 测试连接失败 | 检查 API 根地址是否多写了 `/chat/completions`、密钥是否有效、本机 HTTP 是否仅用 loopback |
| 同步时报 `LLM 认证失败` | 设置页保存的配置没有密钥或密钥无效；填入密钥并点「测试连接」验证。旧 `.env` 中同 origin 的密钥会被自动沿用 |
| 生成草案长时间无进展 | 到运行页查看状态；模型超时/限流会显示原因，可回设置页增大超时后重试 |
| 生成草案报 schema 字段错误 | 模型输出未通过校验且自动修复失败；运行页会显示具体字段，可重试或换模型 |
| 确认冲突、hash 或 revision 不匹配 | 返回首次设置页重新打开最新草案审阅，再确认；不要篡改隐藏字段 |
| 材料过大 | 单份表单上限 512 KiB；合并后超长会自动截断并提示，拆成多份或删减后重试 |
| 提示未完成初始化 | 先连接模型、生成并确认草案；保存材料或生成草案不等于确认 |
| 同步被拒 | 确认当前工作区已完成初始化；检查运行页错误与是否有其他任务正在运行 |
| 同步来源失败/限流 | 换个来源或稍后在运行页显式重试；已采集数据保留，检索式由 Agent 每轮自动更换 |
| 挖掘后队列为空 | 查看运行摘要与队列合格条件；低相关/特殊桶/缺摘要/版本不匹配不会进入主队列；保底填充会在下限内补足并标注 |
| 提示已有任务运行或返回 409 | 队列顶部或运行页查看当前任务，完成后再开始新任务；不会静默排队 |
| 超过 5 分钟无更新 | 检查来源、模型连接和本地服务日志；可能仍在等待请求超时。失败后用相同参数显式重试 |
| 运行中关闭页面 | 从阅读队列页进入最近运行查看；重启造成中断会标记失败，检查后重试 |
| 暂无合格候选 | 挖掘仍算成功；下一轮 Agent 会自动换角度生成检索式；也可换来源、或填一句「本次关注点」引导 |
| 同一天新挖掘的论文没有出现 | 刷新队列筛选条件，并查看任务是否完成“刷新队列”阶段；新流程不依赖日报 |
| 排序日期较旧 | 点击刷新排序；同一天已有快照复用，次日会重新计算 |
| 想重新测试首次设置 | 设置 → 重置工作区 / 清空数据；确认后自动备份再清空，可保留模型连接 |
| 旧工作区升级后提示模型未授权 | 到设置页保存一次模型配置；旧 `.env` 配置只作为回退，不自动获得网页授权 |
| 导入论文时解析失败 | 解析只用于预填：直接在手动填写表单补全标题等信息完成导入，外部来源失败不会卡住流程 |
| 导入提示「该论文已归档/已在库中」 | 这篇论文已在库里：按提示打开详情页修订评分与备注即可，重复导入会被拦截 |
| 导入后同类论文挖掘变少 | 预期行为：导入评分参与挖掘规划，同主标签批量导入会在几周内压低该标签的挖掘补给；导入时不选标签则不参与 |
| 邮件送达不确定 | 人工核对收件箱/服务商记录，勿删记录、降迁移或绕过幂等重发 |

重试会创建新 Run，原失败记录保留。相同 Run ID 和相同输入只执行一次，换输入复用 ID 会冲突。低置信度分类与摘要质量问题仅记录质量标记；没有摘要文本的论文会跳过。特殊桶仅自动接受有效且置信度不低于 0.8 的提名，其余留在主队列。

回滚代码不会撤销已写入的数据；需要恢复旧状态时使用操作前完整副本。不要直接修改 SQLite 状态绕过初始化检查。

## 阅读回顾

| 现象 | 处理 |
|---|---|
| 导入后阅读量没增加 | 导入时间与阅读时间独立；在归档详情补记日或月份。未知日期在全部历史中保留，月精度不计入某个精确周 |
| 历史周报看不到后来补录、更正 | 默认“当时记录”使用历史截止；切换“现在重新回顾”后主动保存新版本，旧快照保持不变 |
| 没有可回顾记录或筛选无结果 | 回到归档完成阅读／导入，或清除主题筛选；未完成首次设置会引导到初始化页，不自动生成研究档案 |
| 保存回顾时提示任务占用 | 打开提示中的现有运行，完成或停止后再提交；工作区内与挖掘、草案提取共享一个任务位 |
| 停止或重启后没有新报告 | 停止在读取批次边界生效，未完成的报告不保存；重启后的未完成任务标为失败，可用原参数重试，已有报告可继续打开 |
| 编辑资产提示其他页面已更新 | 草稿保留在表单中；核对最新版本后再保存，避免覆盖另一窗口的修改 |
| 个人副本无法下载 | 返回导出页勾选私人原文说明；全部历史的个人完整副本选择 JSON，Markdown 用于事实或报告副本 |
| 删除资产后报告仍有正文 | 删除范围预览列出正文副本所在报告，可勾选一并删除；原有下载与备份须自行处理 |
| 想恢复重置或误删工作区的数据 | 先停止服务并保留当前副本，再按 [FAQ 的恢复步骤](faq.md#阅读回顾如何备份与恢复) 恢复完整数据库／目录；个人 JSON 导出目前没有自动导入入口 |
