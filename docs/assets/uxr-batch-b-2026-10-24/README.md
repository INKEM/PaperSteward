## 交互与统计口径

| 场景 | 结果 |
|---|---|
| 搜索 alpha | 顶部统计保持「未读 6 篇」,列表行「符合当前筛选 1 篇(未读共 6 篇) · 清除筛选」 |
| 点「清除筛选」 | 回到无参数干净地址 `/ui/queue`,6 篇全量,统计不变 |
| 空搜索 | 「没有论文符合当前筛选」+「清除筛选,显示全部」按钮 |
| 完成一篇阅读 | 成功片段附带 OOB 统计,顶部未读 6→5 实时同步,无整页刷新 |
| 手机「更多筛选」 | 默认收起为一行芯片(标签/状态/分数隐藏),点击展开为双列,再点收起 |
| 采集参数与检索说明 | 展开面板内含来源/关注点/篇数/数据流向说明,无横向溢出 |
| 控制台 | 全程无 error、无 htmx:targetError |

## 实现说明

- 「更多筛选」用复选框 + label 芯片实现(桌面 `display: contents` 内联流动,手机 `:not(:checked)` 折叠),
  不用 `details`——Chromium 不支持 details 上的 `display: contents`。
- 服务器同一份 HTML 服务两端:桌面无视复选框直显字段,手机由纯 CSS 默认收起,无 JS 参与。
