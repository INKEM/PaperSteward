走查中核对的行为：

1. 只改标题提交修订 → 新版本来源的 `paper_id + archive_hash + rating_at` 与原版本完全一致（页面显示与数据库行双重确认），不再丢失反馈版本（F05）。
2. 历史列表项为链接；版本详情缺失时（`/revisions/99`）返回 404 并提示「资产版本不存在」，不回退最新内容。
3. 表单隐藏 `idempotency_key` 每次渲染生成；同键重放语义由集成测试覆盖（`test_page_revision_resubmission_with_same_key_replays`）。

走查局限：IAB 自动化环境对整页表单的原生点击滚动支持不完整，提交通过浏览器原生 `requestSubmit()` 触发（与用户点击同一表单提交路径；表单结构、`action`、`method` 已逐一核对）。未执行 Docker、其他设备实机与真实打印。
