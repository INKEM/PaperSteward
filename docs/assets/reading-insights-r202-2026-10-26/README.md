# R2-02 浏览器走查记录（2026-10-26）

走查对象：`feat/reading-insights-phase2` 上 R2-02 材料清单、用途授权与摘录的
「阅读分析」页与归档详情摘录块。服务器为真实 Uvicorn + 审计钩子（非回环请求
即失败留痕）；数据库为临时工作区，未触碰用户个人库。

| 场景 | 操作 | 结果 |
|---|---|---|
| 分析页（桌面 1280×900） | 打开 /ui/reading-insights/analysis | 模型连接只读摘要（端点/模型/配置版本）、「连接只在设置页修改」说明、授权表单（本次/持续单选、七类勾选、知情确认必勾）、「还没有授权记录」空态、材料预览折叠表单 |
| 未确认提交 | 只勾类别不勾知情确认直接提交 | 原生 required 约束拦截提交、无请求发出（无 JS 校验路径正确） |
| 保存授权 | 勾选冻结元数据＋备注与个人说明＋确认 | 「已保存授权；模型设置变化后需重新授权。」；列表「工作区持续 · 类别：… · 生效中」＋撤回按钮 |
| 材料预览 | 填论文 ID、勾两类、展开折叠提交 | 「预览已生成；这只读取本地数据，未发送任何请求。」；「选中 1 篇（全部归档 1 篇）」；表格含版本锚点（归档哈希）、内容哈希前缀与限制文案 |
| 撤回 | 原生点击撤回 | 「已撤回授权；之后的分析发送一律拒绝。」；状态变「已撤回 +时间」 |
| 详情页摘录块 | 打开导入归档详情 | 「补充摘录（可选）」块、私人材料说明；填摘录＋出处提交 →「已保存摘录（私人材料，仅本地）。」，列表含「出处：第 3 节」 |
| 数据库行 | 事后核对 | grant 行含规范化端点与类别 JSON、revoked_at 置位；revoke_event 记 reason='user'；摘录行原文与出处一致 |
| 窄屏 390×844 | 分析页与详情页 | 两页均无横向溢出（scrollWidth == clientWidth） |
| 隐私 | 全程 | 审计钩子无外网请求记录；预览与授权全离线 |

## 环境限制（如实记录）

- 截图接口超时（与 R2-00C/R2-01 相同）：以 DOM 快照、HTTP 提示文案、数据库行
  核对为证据。
- 自动化点击兼容性（与 R2-00B/C 相同）：表单填写用页内原生控件赋值＋
  `requestSubmit`/原生 `click()`（页面无自定义 JS 处理器，与用户操作同一提交
  路径）；授权/预览/撤回/摘录语义另由 25 项集成测试独立覆盖。
