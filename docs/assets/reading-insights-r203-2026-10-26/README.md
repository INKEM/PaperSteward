# R2-03 浏览器走查记录（2026-10-26）

走查对象：`feat/reading-insights-phase2` 上 R2-03 单篇分析任务的端到端流程。
服务器为真实 Uvicorn + 审计钩子（非回环请求即失败留痕）；模型端点为本机
127.0.0.1:8123 的假 OpenAI 兼容服务（真实 HTTP 发送路径），数据库为临时
工作区，未触碰用户个人库。

| 场景 | 操作 | 结果 |
|---|---|---|
| 分析页授权（1280×900） | 勾选 冻结元数据＋备注与个人说明＋知情确认 | 「已保存授权」；列表「工作区持续 · 生效中」 |
| 材料预览 | 填论文 ID＋勾备注类别，展开折叠提交 | 「预览已生成；这只读取本地数据，未发送任何请求。」；「选中 1 篇」；**预览页渲染出显式提交表单（含预览令牌隐藏域）** |
| 提交分析 | 点击「提交分析」 | 303 到 `/ui/runs/{id}`；运行页步骤条「排队→逐篇分析→保存→完成」 |
| 真实发送 | 运行执行 | 运行 SUCCEEDED；**本机假端点收到一次真实 HTTP 请求**并返回反思输出；候选经证据核对落库 |
| 运行摘要 | 数据库核对 | `papers_total=1, completed=1, candidate_count=1`；cost_json 记录 `llm_call_count=1`、prompt/completion tokens |
| 派生链 | 数据库核对 | `reading_derived_copy` 登记 `('paper', 论文ID, 'statement', 'candidate')` |
| 候选展示 | 打开 `/ui/reading-insights/analysis?run=…` | 「分析结果」运行行「已完成 · 候选 1 条（完成 1 / 失败 0 / 材料不足 0）」；候选按篇分组：「收获 · 模型归纳（待核对）」＋陈述＋「待核对」；标注「候选未经你确认，不会写入资产或长期画像」 |
| 终态跳转 | run 成功后访问 /ui/runs/{id} | 303 → `/ui/reading-insights/analysis?run=…` |
| 窄屏 390×844 | 分析页与运行页 | 两页均无横向溢出 |
| 隐私 | 全程 | 审计钩子无外网请求（假端点在本机回环）；候选/运行摘要不含备注原文以外发送内容反推；cost 记账完整 |

## 环境限制（如实记录）

- 截图接口超时（与 R2-00C/R2-01/R2-02 相同）：以 DOM 快照、HTTP 状态、
  数据库行与假端点真实请求佐证。
- 表单操作用页内原生控件赋值＋`requestSubmit`（页面无自定义 JS 处理器，
  与用户操作同一提交路径）；全流程语义另由 17 项 runner 集成测试与
  25 项服务集成测试独立覆盖。
