# R2-00C 浏览器走查记录（2026-10-26）

走查环境：真实 Uvicorn（loopback、无模型配置、禁止外网）、独立内存盘工作区、迁移 head `0026`。种子为一篇已归档论文和一个钉住私人标题/正文的「问题」资产，以及两份同周报告：一份未选正文（仅标题副本）、一份选入正文（标题＋正文副本）。

## 核对结果（DOM 快照＋数据库断言）

1. **删除预览**：`GET /reading-insights/assets/{id}/delete-preview` 的 `private_copies` 同时列出两份报告——仅标题副本 `fields: ["title"]`、含正文副本 `fields: ["title","body"]`，`source_revision: 1`，`referenced_reports` 为空。
2. **资产详情删除区块**：两份报告均以复选框列出并标注「（含标题）」「（含标题、正文）」；文案列明将删除资产自身的标题/正文/适用说明；未勾选时明确「保留原副本，可删除整份或另存脱敏版本；已下载文件与备份不会自动收回」。
3. **另存脱敏版本**：仅标题副本报告页提供「另存脱敏版本」；提交后 303 到新报告，页面显示「这是报告 X 的脱敏版本：资产标题与正文副本已移除；原报告未修改」、资产引用显示「（私人标题已移除）」、run 行以纯文本说明「无运行记录」；原报告页仍显示私人标题与另存入口（未修改）。
4. **页面删除流程**：勾选含正文副本的报告删除资产 → 该报告 404 且其副本登记级联清除；未勾选的仅标题副本报告保留并显示「来源已移除」，其标题副本登记保留；脱敏副本与谱系登记不受影响。
5. **窄屏 390×844**：`scrollWidth 375 ≤ innerWidth 390`，无横向溢出（DOM 断言）。
