# R1-06 浏览器验收（2026-10-26）

使用真实 Uvicorn、临时离线 e2e 样例库；不打开用户个人论文库。服务只绑定 `127.0.0.1`，审计钩子禁止非回环连接与 DNS 查询。

| 场景 | 结果 |
|---|---|
| 桌面与窄屏统一次级入口 | 通过；仍归属主导航“归档”，链接自动换行 |
| 窄屏表格、筛选与导出 | 通过；390×844 窗口可用区约 375 CSS px，scrollWidth 与 clientWidth 相等 |
| 切换全部历史到本月并 Ctrl+Enter | 通过；显示对应月份，周／月锚点补为工作区当前日，无关日期字段禁用 |
| 从回顾打开论文再返回 | 通过；保留月份、模式、明细分组与分页参数 |
| 导出默认与原文说明 | 通过；默认事实分享，个人完整副本另有明确原文说明和未勾选的确认框 |
| 控制台 | 未见 error |
| 打印 | 已加隐藏导航与表单、保留表格列头的样式；未执行真实打印预览／物理打印 |
