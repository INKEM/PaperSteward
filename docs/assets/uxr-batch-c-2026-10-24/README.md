# 批次C(UXR-08/09/10)浏览器验收记录

日期：2026-10-24 · 分支 `refactor/quality-experience`（批次C三个提交完成后）  
环境与工具同[批次A](../uxr-batch-a-2026-10-24/README.md)说明：临时工作区（6 篇种子论文）+ 内置浏览器，
种子论文的内容概括槽位为 `what/how/finding/limitation`、证据为 `evidence`，便于断言。

## 验收结果

| 场景 | 结果 |
|---|---|
| 详情页结构（UXR-08） | 徽章「检索/队列中」→ 元信息（作者·年份）→ 模型概括（含「以原文为准」标注）→ 内容概括四槽（问题/方法/发现/局限）→ 可核查证据（折叠）→ 记录阅读 → 不感兴趣 → 推荐依据（默认折叠） | 通过 |
| 详情上下文完成阅读（UXR-09） | 提交 5 分·精读·备注后：提示「已归档「alpha」…」，内容概括/证据仍在，反馈区切换为「我的阅读反馈」评分 5 + 备注 + 修订历史 + 评分/备注修订表单 | 通过 |
| 队列上下文完成阅读（UXR-09） | 成功片段「已归档「beta」…」带论文标题，OOB 未读统计 4→3 同步，无详情正文混入 | 通过 |
| 队列拒绝（UXR-10） | 卡片替换为「已把「delta」标记为不感兴趣」+「移回待处理」入口（旧「恢复推荐」字样不再出现） | 通过 |
| 移回待处理（UXR-10） | 消息如实：「移回待处理状态……下次挖掘时重新评估」；delta 详情页显示 SCREENED 去向说明「重新评估是否入队」 | 通过 |
| 控制台 | 全程无 error | 通过 |

说明：队列卡片「标记为不感兴趣」自带的确认弹窗（data-confirm）不在本批验收范围，
脚本验收时通过移除该属性提交；真实交互中的弹窗行为不变。
