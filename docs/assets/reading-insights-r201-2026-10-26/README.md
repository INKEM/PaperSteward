## 环境限制（如实记录）

- **截图接口超时**（30s，与 R2-00C 相同）：本记录以 DOM 快照读取、页内脚本只读检查、
  HTTP 提示文案与数据库行核对为证据，未留存截图。
- **自动化点击兼容性**（与 R2-00B/C 相同）：IAB 后端对整页表单的 Playwright 原生
  click/check 超时。走查改用页内原生行为：details 的 `.click()` toggle、表单控件原生
  赋值＋`form.requestSubmit(button)` / `button.click()` 提交（页面无自定义 JS 处理器，
  与用户操作同一表单路径）。409 保留输入、清除、重放等语义均由集成测试独立覆盖。
- **程序化 requestSubmit 丢 submitter**：`form.requestSubmit(clearButton)` 经 htmx 提交时
  未带上 `action=clear`（htmx 对程序化 submit 的 submitter 处理），产生了一条与当前
  内容相同的版本 3——服务端如实记录、聚合层按「值未变不产事件」不计修订。
  原生 `button.click()`（与用户真实点击一致）则正确携带 `action=clear`，清除路径验证
  通过。真实用户路径不受影响。
