# 阅读回顾与长期研究资产：功能设计草案

> 日期：2026-10-25。状态：第一阶段“可靠回顾与手工积累”已实现（2026-10-26）；第二阶段模型分析与第三阶段推荐反哺仍为设计。
> 范围：以用户全部已读归档及主观反馈为基础，设计周报、月报、终身画像和系统反哺；不规定代码、接口、数据库结构或模型实现。

## 1. 产品定位与核心取舍

PaperSteward 已能帮助用户找到论文、排出阅读顺序和记录反馈。下一步应帮助用户回答：**我从这些阅读中留下了什么，哪些判断发生了变化，这些积累如何帮助下一次研究与阅读？**

建议增加“阅读回顾”能力，以当前工作区的全部已读归档为长期底座，形成三个互补视角：

| 视角 | 核心问题 | 主要产物 | 用户接下来的动作 |
|---|---|---|---|
| 周报 | 这周哪些阅读值得留下，哪些问题需要继续追？ | 少量阅读收获、反馈变化、待确认资产、下周阅读建议 | 确认一条收获，补一句理由，挑选下一篇 |
| 月报 | 这个月哪些认识形成了积累，哪些方向应调整？ | 专题综合、观点变化、方法与证据整理、下月研究议题 | 整理一个专题，关闭一个问题，提出一个挖掘关注点 |
| 终身画像 | 在已记录的全部历史中，我持续关心什么、怎样判断价值、积累了什么？ | 有时间脉络的研究兴趣、价值标准、知识资产与问题地图 | 找回旧知识，为新任务组织材料，审视研究方向 |

“终身”表示当前工作区所记录的完整历史，不宣称覆盖用户真实的一生，也不推断人格、智力或科研能力。默认各工作区独立，未来跨工作区汇总应是单独选择的能力。

设计坚持六点：

1. **先保留可复用内容，再做漂亮统计。** 一张能在写作时找到出处的证据卡，比“本月读了多少篇”更有长期价值。
2. **事实、用户判断、系统推测分开展示。** 论文说了什么、用户怎么评价、系统推断出什么，始终可区分。
3. **近期兴趣、长期偏好和知识积累分别表达。** 读得多不等于喜欢，喜欢不等于认可结论，读完不等于掌握。
4. **回顾按需生成。** 周报、月报是阅读历史回顾，不恢复日报、定时挖掘、邮件推送或阅读配额。
5. **所有重要结论可回到原始证据。** 展示来源文献、反馈版本、时间范围和适用边界。
6. **反哺保持可理解、可控制、可撤销。** 自动发现先形成建议，涉及研究方向与全局规则的变化由用户明确确认。

## 2. 当前基础与待补信息

以下是本设计对现状的依赖，不能把未来功能写成已经具备。

| 当前已有 | 可以支持什么 | 当前限制 |
|---|---|---|
| 阅读完成时冻结的归档内容、研究档案和分类版本 | 还原阅读时的论文背景与推荐依据 | 导入归档可能没有摘要、标签、机器评分或阅读方式 |
| 1–5 分主观评分、备注、评分与备注修订历史 | 观察价值判断及其变化 | 单一总分不能区分“相关”“可信”“有用”“容易理解” |
| 阅读方式、归档时间、导入来源标记与实际阅读日／月声明 | 形成基本阅读记录与来源分组、按实际周期回顾 | 声明允许未知，归档时间不一定是真实阅读时间；没有可靠阅读耗时 |
| 标签、作者、发表场所及可用的论文概括 | 统计主题覆盖，组织专题候选 | 标签会变；作者可能重名；概括不等于全文证据 |
| 历史推荐参考分及其分项 | 回看推荐与读后感受的差异 | 推荐分与个人评分衡量不同内容，不能直接相减 |
| 偏好分使用标签、作者、发表场所上的显式评分 | 在现有排序中体现阅读偏好 | 按周冻结，不消费阅读备注；不能理解评分理由 |
| 检索规划使用近期评分记录与队列覆盖 | 让后续挖掘参考近期阅读 | 当前近期窗口为 8 周且有记录数上限，不是全历史画像 |
| 归档导出、事实回顾报告与手工资产版本 | 保留可追溯的阅读事实与个人收获／问题 | 尚无模型生成的跨文献证据卡、知识提炼与自动画像 |

现有阅读备注只在本地保存，不发给模型。本设计不会把既有模型授权解释为备注分析授权。外部模型分析备注及衍生内容的边界见第 11 节。

## 3. 数据范围与统计口径

### 3.1 全历史底座与当期增量

- 全部已读归档都是分析对象，包括系统内完成与系统外已读导入；缺失信息单独标注，不因没有模型概括就排除论文。
- 周报、月报以当期新增阅读、补录、反馈修订和资产变化为主线；回看历史时可以关联旧文献，说明“这是本期变化与历史积累的联系”。
- 同时提供“全部历史”“近期”“选定专题”视角。局部筛选必须标明范围，不能把筛选结果称为完整画像。
- 待阅读队列、被标为不感兴趣的文献，只作为另行标明的辅助上下文，不混入已读文献的分母。
- 分析全部归档不等于每次把全文历史发送给模型。历史事实统计覆盖全部记录；内容综合应披露实际覆盖文献和未覆盖原因，不能把抽样分析包装成全量理解。

### 3.2 必须区分的时间

| 时间 | 用途 | 缺失时的处理 |
|---|---|---|
| 论文发表时间 | 观察经典与新研究的阅读结构 | 归为“发表时间未知”，不猜年份 |
| 实际阅读时间 | 回顾某周、某月的阅读活动 | 系统内完成可用标记完成时间作为记录口径，但说明不等于阅读开始时间 |
| 归档／导入时间 | 观察本期新增了哪些记录 | 历史导入单列为“本期补录”，不冒充本期新读 |
| 反馈修订时间 | 观察观点与价值判断的变化 | 记作本期修订，不重复增加已读篇数 |
| 资产确认／使用时间 | 观察知识是否被整理与复用 | 未记录使用只表示“尚未记录”，不表示从未使用 |

建议未来允许导入时选填实际阅读日期或大致月份，支持“日期不详”。历史数据不倒推阅读日期。只有月份的记录进入月度统计，不任意分配到某周。

默认按工作区时区，周一至周日为一周，自然月为一月；本周、本月未结束时标注“截至当前”。切换时区后查看旧报告，保留报告原有时间口径。

### 3.3 去重、缺失与版本

- 一篇论文在同一统计范围内只计一次；补录、评分修订和备注修订不会变成多篇阅读。未来记录重读时，分别展示“独立文献数”和“阅读次数”。
- 同一文献的预印本和正式版若已确认属于同一研究，可关联展示；疑似重复先提示用户，不自动合并不同研究。
- 未评分不当作中立分或低分；无备注不当作没有收获；缺标签归入“未分类”。所有指标展示有效样本数及覆盖率。
- 默认历史报告使用“周期结束前已记录的信息与最后有效反馈”。本期报告使用生成时的截止信息；以后有新增记录或修订，只提示有更新，不改写已保存报告。
- 补录了过去读过的论文后，可以选择“基于现在的信息重新回顾过去”，生成新版本，并标注补录数量及知识截止时间；不能伪装成当时已经知道。
- 初始评价、当时评价、当前评价分别可查。长期画像默认使用当前有效评价，同时保留变化轨迹；评价修订多次仍只贡献一个当前偏好样本。
- 主题趋势默认保留阅读时的分类；需要跨分类版本观察时，另展示经确认的统一主题映射，无法对应的部分单列，避免把改名误判为兴趣转移。

## 4. 从哪些角度提炼价值

以下各角度都应回答“发现了什么—依据是什么—能做什么”，不以堆积图表为目标。

| 分析角度 | 如何提炼 | 有价值的输出 | 可反哺的位置与边界 |
|---|---|---|---|
| 阅读结构与节奏 | 按实际阅读记录、阅读方式、主题和发表年代分布；补录单列 | 最近集中读什么，哪些方向持续覆盖，哪些反馈待补 | 阅读回顾和安排建议；不根据篇数给用户打绩效分 |
| 主观价值来源 | 结合分布、用户选填理由及获准分析的备注，区分方法、启发、证据、应用价值 | “你近期高评价主要来自可复用的评估方法”及支撑论文 | 推荐理由和检索侧重点；总分本身不能证明原因 |
| 稳定偏好与阶段兴趣 | 比较近期窗口、前一窗口及全历史，结合不同月份和不同文献的重复证据 | 长期关心的问题、新出现的兴趣、只在一个项目出现的需求 | 检索规划与排序偏好；单次高分只作线索 |
| 主题覆盖与盲区 | 对照用户已确认方向、已读分布、待解决问题和队列覆盖 | 某问题已有较多方法论文，但少有边界条件或负面结果 | 提议补充检索或阅读视角；“没记录”不等于“用户不懂” |
| 问题—方法—场景 | 从已有概括、摘要及用户确认内容整理研究问题、方法、数据与应用条件 | 某方法适用于什么问题、约束下应查哪几篇 | 个人方法库与专题检索；没有全文时限制结论粒度 |
| 论点、证据与分歧 | 将具体主张连接到来源及研究条件，比较可比研究的支持、限制和不同结果 | 可引用的证据组、待核实分歧、需要补充的验证 | 写作、研究设计和反例检索；主题相似不自动构成证据关系 |
| 跨文献连接 | 寻找相同问题的不同解法，或不同领域中相似约束的处理方式 | 可供用户审视的方法迁移或组合思路 | 探索阅读与实验想法；明确是系统提出的候选联系 |
| 判断变化 | 比较同一论文不同时间的评分与备注，询问变化原因 | “原来觉得适用，实际使用后发现条件不符” | 更新方法的适用边界；不把降分直接解释为论文错误 |
| 知识复用与落地 | 让用户轻量记录已引用、已用于实验、已作为基线或已推荐给他人 | 真正反复使用的论文、工具和方法，未落地的行动 | 增强复用导向推荐；被收藏和高评分不算已使用 |
| 开放问题与研究机会 | 从显式疑问、局限和多次未解决的需求中归并问题，附已有证据与缺口 | 可继续追踪的问题、阅读路径和实验候选 | 下一次挖掘的关注点；只表示个人阅读中的缺口，不宣称领域首创 |
| 作者与发表场所线索 | 在有足够不同论文、多个时期反馈后，呈现用户体验与样本 | 对某研究群体的持续关注，来源覆盖过窄的提醒 | 作为弱检索线索；处理重名，不以声望代替论文本身 |
| 系统推荐的适配情况 | 对有历史推荐依据且已反馈的论文，交叉查看推荐分项、读后评价和理由 | 高相关低实用、低预期高收获等可解释案例 | 修正推荐解释和提出调优建议；仅代表已读反馈样本 |

### 4.1 让主观反馈更有解释力，但保持轻量

保留现有“评分＋备注”即可完成归档。新增信息全部可选，在用户愿意整理时逐步补充：

- **为什么有价值／为什么价值有限**：例如方法可复用、改变认识、支撑论证、与任务无关、证据不足、内容已知、暂时看不懂；允许多选和自定义。
- **留下一句话**：我学到了什么、不同意什么、准备怎样使用；可只填其中一项。
- **关联当前问题或项目**：解释“这篇为什么对我有用”，避免项目需求被误认为永久偏好。
- **后续动作及结果**：待复现、待引用、待比较、已使用、不再需要；动作是可选清单，不另建强制任务流。
- **评价的适用语境**：例如“作为入门综述很好，但不能直接指导实验”。

界面先展示少量理由选项与一句话输入，其余折叠。一次低分只引出一个可跳过的追问：“主要是暂时不适合，还是内容本身有疑问？”不要求用户给每篇论文填写长问卷。

分析时分别表达个人相关性、个人使用价值、理解状态、用户对证据的评价。单一总分无法拆出这些维度时，如实保留未知，不自动补分。

### 4.2 从原始记录到结论的约束

每条洞察至少带上：一句结论、证据文献与反馈片段、时间及样本范围、结论性质、适用限制、可选下一步。

结论性质分为：

- **记录事实**：如“本月 6 篇已读中，4 篇有评分”。
- **用户明确表达**：如“你在两条备注中写了想复用评估协议”。
- **系统归纳待确认**：如“你可能开始更重视部署条件”。
- **用户已确认判断**：用户认可了归纳的措辞及边界，仍保留证据和时间。

不展示没有校准依据的“87% 确信你喜欢某方向”。用“单篇线索／多篇一致／跨期持续／存在相反证据”等描述，并显示真实样本。只有一篇论文时可以形成一张知识卡，但不能据此宣布长期偏好。

建议初始保守规则：至少来自 3 篇不同文献、跨 2 个自然月的同类反馈，才出现“可能是稳定偏好”的候选；这只是产品展示门槛，不是统计显著性证明。冲突理由或单一项目集中样本会继续降低表述强度。

## 5. 周报：把最近的阅读转成可留下的收获

### 5.1 默认结构

周报应能在几分钟内读完，默认突出不超过 3 条收获和 3 个下一步，数量不足时少展示。

| 模块 | 内容 | 默认动作 |
|---|---|---|
| 本周记录 | 新读独立文献数、补录数、评分及备注覆盖率、反馈修订数 | 查看本期论文及统计口径 |
| 最值得留下 | 按用户明确收获与反馈选出重要内容，关联必要的旧文献 | 保存为知识卡／关联已有资产 |
| 新连接与疑问 | 新出现的问题、与旧阅读的联系、尚不确定的判断 | 确认问题／忽略候选联系 |
| 回头看 | 旧论文的评分变化、追加使用结果、曾留问题的新进展 | 查看变化前后及补充原因 |
| 下一步阅读 | 与开放问题相关的队列论文、值得重读的归档，以及需要补查的方向 | 打开论文／带入挖掘表单 |

“最值得留下”不只是本周最高分列表。高分且没有理由的论文可列为“你评价较高，尚未记录原因”；低分但暴露重要限制的论文也可能产生有价值的资产。

### 5.2 历史关联与特殊情形

- 本周新文献可以与多年以前的阅读关联，说明旧文献为何重新相关，而不是每周重复总结所有历史。
- 只有补录时，标题说明“本周整理了历史阅读”，展示新增的长期资产线索，不评价本周阅读节奏。
- 没有新读但修订了反馈或使用了旧方法时，仍可生成有内容的回顾；完全没有变化时显示“本期暂无新增记录”，不生成空泛鼓励。
- 本周只读一篇时，围绕一篇的收获和疑问展开，不输出趋势或偏好结论。
- 缺备注、模型不可用或用户未开放文本分析时，提供事实版周报，支持用户手动补写收获。

## 6. 月报：形成专题判断与研究方向复盘

月报直接回看当月原始记录与相关历史资产，不依赖用户先生成四份周报，也不简单拼接周报。

### 6.1 默认结构

1. **本月形成了什么认识**：按 2–4 个有材料支持的专题组织，分别列出问题、重要认识、支持证据、限制和待确认部分。
2. **哪些判断发生了变化**：本月新证据如何补充、收窄或挑战过去判断，用户是否认可这种解释。
3. **积累了哪些可复用方法与证据**：新增、修订、合并、实际使用的资产；突出可在写作和实验中直接找回的内容。
4. **兴趣与阅读结构怎样变化**：对照上一个完整月和长期背景，说明新兴趣、持续方向和暂时减少覆盖的方向；不把项目性集中阅读直接称为转向。
5. **哪些问题仍未解决**：持续出现的疑问、支持与反对证据不足之处、已解决或不再重要的问题。
6. **下个月可以关注什么**：少量议题、队列阅读路径、旧文重读及挖掘建议，允许用户直接删改。

月报可包含“专题证据表”，例如：

| 围绕的问题 | 当前认识 | 支持材料 | 限制或不同结果 | 下一步 |
|---|---|---|---|---|
| 方法是否适用于低资源部署？ | 已读材料支持其在特定实验设置中有效 | 论文 A 的摘要陈述＋用户读后记录 | 论文 B 场景不同，暂不能直接比较；缺少部署测量 | 查找可比测量，或用户补充原文依据 |

表中的论文 A/B 为格式示例，实际报告必须链接到真实归档。系统没有相关材料时不生成该结论。

### 6.2 月度比较口径

- 显示“4/6 篇有评分，其中 3 篇为 4–5 分”，比只有平均分更容易解释。平均分如提供，必须同时展示分布与样本量。
- 不将 1–5 分当作精确等距的科研质量尺度；不同月份评分标准变化时，优先展示用户的评价理由与修订。
- 未结束的月份只与上月相同经过天数比较，并说明日期；也可仅展示当期，不强行计算环比。
- 样本较少时列出代表性记录和差异，不渲染增长百分比。标签多选的分布可能重叠，明确是主标签占比还是多标签覆盖。
- “盲区”必须锚定已确认目标或开放问题。用户没有覆盖某方向，不自动意味着需要补课。

## 7. 终身画像：有历史的研究记忆

画像应是持续积累、可检索和可纠正的研究记忆，而不是一句固定的人设描述。默认展示当前摘要，能够展开时间脉络和全部证据。

### 7.1 画像分层

| 层次 | 包含内容 | 更新原则 |
|---|---|---|
| 已确认研究目标 | 用户明确设定的问题、边界、纳入与排除规则 | 沿用设置页重新生成并确认研究档案的流程；行为推测不能覆盖 |
| 长期价值标准 | 用户持续重视的证据形式、可复用性、方法或应用约束 | 多篇、跨期证据形成候选，用户可确认、纠正或停用 |
| 阶段兴趣与任务 | 最近关注的主题、项目、阅读目的及有效期 | 显示近期依据，允许设置本次／阶段性适用，不固化为永久规则 |
| 知识与方法资产 | 用户确认的认识、方法卡、证据组、专题阅读路径 | 持续增加来源、边界和使用记录，旧版本可回看 |
| 开放问题与判断变化 | 未解问题、分歧、改变看法的轨迹 | 可解决、搁置、重新打开；保留为什么变化 |

“熟悉程度”如展示，使用“有阅读记录／有个人总结／有实际使用记录”等可观察描述。没有测验或用户确认，不使用“精通”“已掌握”等能力评级。

### 7.2 画像条目的呈现与控制

每条画像包含：判断内容、适用场景、首次及最近证据、来源文献数、相反证据、确认状态、允许影响的系统环节。

用户可执行：确认、修改措辞、标记仅当前项目适用、暂不采用、停止用于推荐。误判时可选择原因，例如“只是这次任务需要”“标签不对”“不代表喜欢这个方向”。

状态语义：待确认 → 已确认；之后可修订、停用或标为需复核。忽略一个建议不等于反向偏好。近期没有新证据只显示“最近未补充”，不会删除长期资产；出现新的相反证据时，提示复核而非悄悄替换。

### 7.3 长期资产如何供用户取用

- **按问题查找**：“我以前读过哪些关于评估泄漏的论文，有什么可用结论？”返回相关文献、已确认资产和未解决疑问。
- **按用途查找**：“给实验选一个基线”“给这段论证找依据”“快速回忆某方法的限制”。先返回已有证据，缺口明确展示。
- **按变化查找**：“我为什么不再推荐这个方法？”并列初始评价、后来评价及触发材料。
- **按专题整理**：将文献、认识、方法和问题组织成专题包；支持导出有来源的阅读综述提纲或方法清单。
- **追踪再利用**：从论文卡或资产卡记录“已引用／已使用”和结果；未来回顾可以发现使用后的评价变化。

最先提供标签、关键词、问题和资产类型筛选；自然语言查找属于后续增强。当前词面哈希 embedding 的结果只能作为检索线索，不能被包装为精确知识距离或能力地图。

## 8. 资产：从一次性报告到持续积累

报告是某个时间点的回顾，资产是可持续修改与引用的内容。周报和月报应链接到同一资产，避免每期复制一份相似卡片。

| 资产类型 | 核心内容 | 形成路径 | 再利用场景 |
|---|---|---|---|
| 认识卡 | 一条认识、适用范围、限制、来源 | 一篇的明确收获，或多篇的综合判断 | 快速回忆、形成论证 |
| 方法卡 | 解决的问题、前提条件、关键做法、资源／数据要求、局限 | 用户确认的方法提炼 | 实验设计、复现和工具选择 |
| 证据组 | 待支持的论点、支持／限制材料、研究条件及出处 | 用户整理或确认的跨文献关系 | 写作引用、观点核查 |
| 问题卡 | 问题、已有认识、缺失证据、下一步、当前状态 | 阅读中的疑问或项目需求 | 定向挖掘、后续研究 |
| 阅读路径 | 一组有顺序的论文及每篇的作用 | 已读历史和用户确认的依赖关系 | 回顾专题、进入相邻方向 |
| 使用记录 | 某资产用于何处、结果与新限制 | 用户主动补记 | 衡量实际价值、修订画像 |

所有资产保留以下语义：

- 来源指向原始归档、具体反馈版本或用户补充的原文片段；仅有摘要时明确“摘要级依据”，没有页码就不编造页码。
- 论文陈述、个人判断、模型归纳有独立标记。多篇概括不能相互循环引用来增加可信度。
- 候选资产可出现在回顾中，但默认不作为系统已确认知识。用户保存时可以改写、合并、关联或拒绝。
- 同一问题的不同结论可以并存。优先呈现研究条件差异；不足以判断时标为“待比较”，不强行宣布矛盾。
- 新材料到来时，建议“补充来源／收窄适用范围／另建相反观点”，用户确认后形成新版本，保留变化理由。
- 资产能够独立于模型保留和导出。更换模型服务后，用户整理的内容及证据关系仍然可用。

长期累积的重点是减少再次查找、重新理解和重复整理的成本。资产数量本身不作为成功指标；系统不应为了凑数生成大量同义卡片。

## 9. 如何反哺系统

### 9.1 反哺路径与生效边界

| 反哺位置 | 消费的信息 | 用户可见的变化 | 生效边界 |
|---|---|---|---|
| 检索规划 | 已确认问题、长期价值标准、阶段关注点、已有方法与证据缺口 | 建议检索式解释“在补哪个问题、基于哪些阅读” | 用户手动挖掘时使用；单次关注点优先，显式排除规则优先 |
| 队列排序与推荐解释 | 适用的已确认偏好及使用价值；候选相对已读资产的新信息 | 区分“延续已知方向”“补缺口”“带来新方法”，解释影响原因 | 新增学习信号先预览并启用；现有按周评分偏好继续按原规则工作 |
| 阅读辅助 | 与当前论文有关的旧认识、方法、分歧和问题 | 详情页提示“你曾读过什么、这篇可能补充哪里” | 提供可核查关联，候选联系明确标注；不替用户声称理解了论文 |
| 已读资产召回 | 相关问题卡、证据组和方法卡 | 建议优先重读已有论文，减少重复挖掘和重复整理 | 不为制造新内容而强制联网 |
| 反馈收集 | 已知的歧义和缺失理由 | 对关键样本给出一个可跳过的补充问题 | 不提高普通归档的必填要求 |
| 研究档案维护 | 行为与已确认目标的持续差异 | 提示“是否把这个方向加入下一版研究档案”，附证据 | 只生成修改建议，通过设置页重新生成并确认；不直接激活新方向 |
| 全局评分治理 | 多个有理由的推荐偏差案例 | 给出权重调整建议与影响预览 | 仅沿用现有允许的线性权重治理范围；确认及生效日规则不变 |

未来的新增学习能力默认先处于“仅用于回顾”。用户可独立启用“用于检索建议”“用于排序”，并随时停用。启用时能看到具体使用哪些画像条目，而不是一个无法解释的“个性化开关”。

“已知内容很多”可以降低某论文的阅读紧迫性，但不能成为自动淘汰条件：新验证、反例、不同应用条件仍可能有价值。已有入队硬门槛、保底填充规则、长期队列完整展示均保持原产品边界。

### 9.2 避免越用越窄

- 喜欢某方法，不意味着只查支持该方法的论文；开放问题可建议同时检索限制条件、替代方法和不同结果。
- 高评分方向与用户主动选择的探索方向并列。探索强度由用户决定，不能自动把低样本方向压到不可见。
- 同一证据影响检索、偏好分和新资产时，说明它们的共同来源，避免把一次评分叠加成多个独立强信号。
- 不把长时间未读、没有备注、没有点击当作负反馈。明确“不感兴趣”的辅助信号也需区分方向无关与当下不适合。
- 作者与发表场所偏好只能是弱线索；不能因一两篇不喜欢就屏蔽某作者或来源。
- 近期窗口用于适应变化，长期记录用于保留记忆，两者并列解释；新兴趣不能抹去旧资产，旧偏好不能锁住新方向。

### 9.3 反哺之后也要回看效果

用户采用建议时记录“采用了哪条、作用于哪次挖掘或排序”，之后在有实际反馈时呈现结果，例如“由这个问题带来的 5 篇入队论文中，已读 2 篇；其中 1 篇被标记为可复用”。

这只能说明已反馈样本的体验，不能据此宣称推荐整体准确率或因果提升。未展示、未入队或未阅读的论文没有可靠评价；无对照时不声称“系统提升了 20%”。排序预览只能说明名次变化，不能代替实际效果验证。

## 10. 页面与完整使用流程

### 10.1 信息入口

建议从“归档”进入“阅读回顾”，避免新增多个平级导航项。回顾区提供“本周／本月／全部历史”和已保存报告；长期资产可从回顾区及论文详情双向进入。

默认页面先展示本地事实摘要和已有报告。用户选择范围并点击“生成回顾”后，才执行明确选定的内容分析；打开页面不会自动联网。已有报告有新数据时显示“有新记录，可更新”，由用户主动生成新版本。

### 10.2 一次回顾的流程

1. **选范围与模式**：本周、本月或自选周期；事实回顾、用户手动整理、获准的模型辅助分析；明确数据覆盖与缺失。
2. **预览分析内容**：包括多少篇文献、多少条反馈、是否含私人备注、使用本机还是外部模型；需要外部模型时说明费用可能发生。
3. **生成并查看**：事实数据、综合认识与待确认建议分区；失败时保留已生成的事实结果，允许按需重试。
4. **沉淀少量资产**：对值得留下的条目执行保存、改写、关联或忽略，不要求逐条审核整份报告。
5. **选择反哺动作**：把问题带入下一次挖掘、打开队列阅读路径、提出档案修订建议；具体执行仍由对应入口完成。
6. **保留与导出**：保存带范围和版本的报告，导出前选择是否包含备注、画像及未确认推测。

长时间分析使用现有任务反馈方式，说明覆盖进度，允许停止；同工作区有其他互斥任务时明确提示待其完成后重试，不悄悄排队。已有报告和本地事实仍可阅读。

### 10.3 用户纠错与控制

- 每个洞察支持查看依据、修正、标记不适用。纠错会影响后续回顾和待确认建议，旧报告仍可查看原版本及更正说明。
- 可以为某篇文献、某条备注或某项资产选择“不用于分析／不用于系统学习”，并展示会影响哪些派生内容。
- 停用某条画像立即停止其后续系统影响；已经生成的建议标记过期，执行前需刷新。既有归档和历史推荐记录不被改写。
- 不提供“一键应用全部推测”作为主操作。影响研究方向或全局配置的建议分别显示具体差异，并进入既有确认流程。

## 11. 隐私、本地优先与信任

### 11.1 分开授权不同数据用途

| 模式 | 可以使用的内容 | 体验与边界 |
|---|---|---|
| 本地事实回顾 | 本地归档、评分、时间、标签等已有记录 | 无需外部模型即可使用；私人备注可供本地展示和手动整理 |
| 不含私人文本的模型辅助回顾 | 用户选定的元数据、摘要、评分及允许的结构化理由 | 本次分析明确列出发送范围；既有模型授权不自动延伸到新用途 |
| 私人文本辅助分析 | 用户明确选择的备注、个人收获、问题及资产内容 | 独立选择本机模型或外部端点，预览材料，按篇或条排除；默认关闭 |

从备注归纳出来的画像、问题和方法评价同样可能暴露私人研究计划。不能因为“已经是摘要”就绕过授权，也不能在用户只授权本地分析后把结果送进远程检索规划。

授权粒度建议支持本次使用与当前工作区持续使用。即使持续授权，也能随时查看、排除材料并撤回；更换端点或扩大内容类别时重新说明。页面浏览、手动整理和事实统计始终不依赖开启私人文本分析。

### 11.2 资产生命周期与导出

- 备注更正、撤回分析授权或排除材料后，列出受影响的报告、资产和画像。停止后续使用；删除用户选择的派生副本，或标记来源已撤回、需要重新生成。
- 已保存历史报告如含不再希望保留的私人内容，允许单独删除报告或生成脱敏副本；不可变原始归档与新增回顾资产分开治理。
- 本设计不引入原始归档逐条删除能力；原始数据仍按现有归档和工作区重置规则管理，不能用“撤回学习”冒充删除原始数据。
- 撤回不能收回已经发给外部端点的请求，也不能收回用户自行导出的文件，操作说明需说清这一点。
- 报告、资产和画像支持可读文本及结构化导出，包含来源标识、范围、版本、确认状态和变更关系；私人原文默认不进入分享副本。
- 系统论文文本与备注均作为分析材料，不作为行为指令；其中出现的要求不应触发配置修改、网络动作或数据外发。

## 12. 指标：如何判断功能有价值

先衡量是否帮助用户找回和复用知识，再观察系统适配。初期可以只在本机形成用户自用的记录，不新增遥测。

| 想验证的问题 | 可观察信号 | 解释限制 |
|---|---|---|
| 回顾是否提炼出有用内容？ | 用户保留／改写的洞察，愿意保留的原因，主动纠错案例 | 保留率高不代表事实正确，应同时检查来源是否充分 |
| 资产是否真的被复用？ | 显式记录的引用、实验使用、旧文重读及结果 | 没有使用记录不能视为无价值 |
| 资产能否被找回？ | 给定实际任务时是否找到所需资产、是否追到原文 | 搜索点击或页面停留不能代替任务完成 |
| 是否减少了反馈负担？ | 用户自述负担、可选字段放弃情况、是否仍能快速归档 | 不以填写越多越成功 |
| 反哺是否更贴合需求？ | 已采用建议对应的后续评价理由及使用结果 | 存在选择偏差；不输出无依据的整体准确率 |
| 画像是否可控可信？ | 误判是否易纠正，停用后是否继续影响系统，来源与授权是否清楚 | 不以用户很少纠错证明系统正确 |

## 13. 分阶段范围与验收情境

### 第一阶段：可靠回顾与手工积累

范围：全归档事实统计、周／月时间口径、补录分流、反馈变化、事实版报告保存与导出；用户手工记录收获和问题、保存基础资产。提供全部历史事实视图，但不宣称已经生成完整知识画像。

代码落实拆为六批，见[第一阶段分批实施计划](reading-insights-phase1-plan.md)；R1-01 至 R1-06 已完成，发布验收记录见计划第 12 节。

验收情境：

- 同一周完成 2 篇新阅读、补录 50 篇旧论文，周报分别显示；未知日期的 50 篇进入全历史底座，不进入本周新读量。
- 只有标题和评分的导入文献仍参与适用统计；内容提炼显示材料不足，不虚构方法、发现或局限。
- 同一论文修改 3 次反馈，已读数仍为 1；历史报告维持当时版本，新报告可显示评价变化。
- 没有模型、没有备注或没有新阅读时，事实回顾仍正常可用，空态如实说明。
- 未生成过周报也能生成月报；未结束月份和跨时区报告的日期口径清楚。

### 第二阶段：有证据的知识提炼

范围：可选结构化反馈、按授权的文本归纳、跨文献专题、方法卡和证据组、长期画像候选及用户确认。候选只用于回顾和资产整理。

验收情境：

- “5 分，但只是综述写得清楚”不会被提炼为“认可该方法有效”；“2 分，因为暂时不适合项目”不会形成领域排除规则。
- 只有单篇高评价时显示偏好线索，跨期多篇证据才提示稳定偏好候选；相反反馈同时可见。
- 两篇论文结论不同但场景不同，输出待比较条件，不直接声称相互否定；无全文时不编造引文和页码。
- 未授权私人文本分析时，不发送备注及其私人衍生内容；更换端点、撤回授权后，相关内容的后续使用可核查。
- 用户纠正画像或合并资产后，下一次回顾能够沿用更正，报告不会不断产生同义副本。

### 第三阶段：可控反哺与实际复用

范围：用户启用后的检索上下文、阅读关联、旧资产召回、排序影响预览、档案修订建议、建议采用后的回看；增强按问题查找与专题导出。

验收情境：

- 用户选择“本次探索新方向”，已确认旧偏好不会压过这次明确意图，也不会突破用户显式排除条件。
- 阅读回顾提出一个问题，用户能查看依据、带入挖掘表单、手动执行，并回看该次结果。
- 停用画像后，未来检索和排序不再消费该条信号；历史归档、已读评价及旧推荐记录保持可追溯。
- 调整研究方向仍须设置页重新生成并确认；权重建议只经过既有治理入口，不能修改入队门槛等非权重规则。
- 不增加定时任务、推送、队列隐藏或每日配额；不同工作区的信息和授权不会自动混合。

以上为产品验收情境，不是实施任务或技术测试方案。每阶段都能独立产生用户价值，后续阶段不以积累大量自动推测为前提。

## 14. 连贯示例：一次阅读如何积累并反哺

以下为虚构情境，用于说明功能行为。

用户此前读过 12 篇检索增强生成相关论文，近期完成论文甲并评分 5 分，备注：“评估方法可以直接用于我的实验，但结论只覆盖英语数据。”本周又补录去年读过的论文乙，评分 4 分，实际阅读日期仅记得月份。

1. **周报**：本周新读 1 篇、补录 1 篇；甲产生“可复用评估方法”的资产候选，并保留英语数据的限制。乙进入历史资产，不增加本周新读数。
2. **用户确认**：将候选保存为方法卡，关联“多语言检索评估”问题，选择只用于当前项目；没有确认“长期偏好多语言研究”。
3. **月报**：本月另一篇论文丙补充了多语言设置，但实验条件不同。月报形成评估条件对照，保留“尚缺可比实验”的问题，不声称多语言有效性已被证实。
4. **终身画像**：若未来多月、多篇反馈都重视可复用评估设计，才提出长期价值标准候选。用户可认可“重视可复用评估”，同时拒绝把具体任务扩展为长期方向。
5. **反哺挖掘**：用户选择“继续查找可比的多语言评估”，系统带入已确认问题与条件缺口。私人文字只有在对应端点获准使用时才进入规划上下文，否则由用户另写本次关注点。
6. **再次使用**：用户按方法卡做实验后，把甲的评价改为 3 分，并记录资源要求过高。下次回顾展示变化，为方法卡补充资源约束，不把旧报告或初始评价覆盖掉。

这样，一条评分与一句备注最终变成有来源的方法、可追踪的问题、可修订的价值判断，以及下一次阅读可用的上下文。

## 15. 建议先确定的产品选择

- 首个版本以“事实回顾＋手工确认资产”为主线，先建立可信口径和积累入口。
- 周报偏向提炼增量与行动，月报偏向跨文献综合，终身画像偏向长期记忆与召回，三者共享资产。
- 可选理由优先于增加更多评分维度；先让高分、低分变得可解释，避免评分表膨胀。
- 自动归纳与系统学习分开启用，私人文本及其衍生内容有独立用途授权。
- 全历史覆盖优先于“看起来聪明”：样本、缺失、历史补录、分类变更和相反证据都应可见。
- 跨工作区汇总、全文级证据、自动任务与外部知识库同步不进入首期范围；以后如扩展，应分别明确来源能力、授权和产品边界。
