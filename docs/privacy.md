# 隐私与数据流向

PaperSteward 面向本机单用户，默认绑定127.0.0.1，没有登录系统。数据库保存研究方向、分类法、论文元数据和摘要、评分、审核、阅读备注、归档及运行记录。没有遥测，网页脚本、样式和字体无需外部 CDN。

| 动作 | 数据去向 |
|---|---|
| Starter 校准 / 试运行 | 本地合成资料，无真实网络调用 |
| 打开、浏览、审核、阅读反馈 | 本地 SQLite |
| 同步采集 | 检索词发送到所选文献源，来源可见网络请求 |
| 真实模型处理 | 论文元数据、摘要及任务所需研究方向/分类规则发送给配置的模型端点 |
| 备注与个人阅读反馈 | 本地保存；备注不传给模型 |
| 导出 / 本地日报文件 | 用户选择的本地文件，可能包含备注 |
| 显式邮件投递 | 日报内容发送给已确认渠道中的收件人 |

真实处理需要 G1–G4 已确认、G4 数据范围允许、模型已配置，以及网页本次同步勾选授权；CLI 使用显式 `--live`。选择离线体验不会偷偷访问真实模型，打开今日页不会自动采集或发邮件。网关可能按有限次数重试瞬时错误；UI 失败后不会无限重新启动整条任务。

外部服务如何保留请求由其政策决定。模型密钥仅从环境/.env读取，敏感字段在日志中脱敏；不要把密钥写进自由文本、截图或 issue。论文文本是不可信数据，不作为执行指令。

应用重启会将未完成的 UI Run 标记失败，保留已完成数据。阅读归档和历史日报保持不可变；没有网页删除数据库/重置门禁功能。需要新工作区时使用新的数据目录。

导出文件含研究偏好或备注，分享前自行检查。更换设备前停止服务、复制完整数据目录并保管好；容器卷也需单独保存。详细配置见[配置指南](configuration.md)。
