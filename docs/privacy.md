# 隐私与数据流向

PaperSteward 面向本机单用户，默认绑定 `127.0.0.1`，没有登录系统。数据库保存研究方向、分类法、上传材料、论文元数据和摘要、评分、审核、阅读备注、归档及运行记录。没有遥测，网页脚本、样式和字体无需外部 CDN。

| 动作 | 数据去向 |
|---|---|
| 保存模型设置 | 地址、模型名、密钥和同意状态写入本地 SQLite；密钥只显示掩码 |
| 生成 / 修改研究草案 | 上传材料、历史意见和上一版草案发送给配置的模型端点 |
| 打开、浏览、审核、阅读反馈 | 本地 SQLite |
| 同步采集 | 检索词发送到所选文献源，来源可见网络请求 |
| 处理论文 | 论文标题、摘要及任务所需研究方向/分类规则发送给配置的模型端点 |
| 备注与个人阅读反馈 | 本地保存；备注不传给模型 |
| 导出 / 本地日报文件 | 用户选择的本地文件，可能包含备注 |
| 显式邮件投递 | 日报内容发送给已确认渠道中的收件人 |

**授权边界**：在设置页保存模型配置即表示同意把论文标题与摘要发送给该服务，用于筛选和概括；确认草案时写入的运行参数记录 `external_model_data=metadata_abstract`。同步不再逐次弹授权，但打开今日页不会自动联网。CLI 的真实模型调用仍要求显式 `--live`。

模型密钥从数据库或环境变量读取，日志中脱敏；页面只显示末四位掩码，密钥不进入运行报告、prompt 或归档。论文文本是不可信数据，不作为执行指令。

外部服务如何保留请求由其政策决定。网关可能按有限次数重试瞬时错误；UI 失败后不会无限重新启动整条任务。

应用重启会将未完成的 UI Run 标记失败，保留已完成数据。阅读归档和历史日报保持不可变；没有网页删除数据库/重置初始化记录的功能。需要新工作区时使用新的数据目录。

导出文件含研究偏好或备注，分享前自行检查。更换设备前停止服务、复制完整数据目录并保管好；容器卷也需单独保存。详细配置见[配置指南](configuration.md)。
