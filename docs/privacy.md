# 隐私与数据流向

PaperSteward 面向本机单用户，默认绑定 `127.0.0.1`，没有登录系统。数据库保存研究方向、分类法、上传材料、论文元数据和摘要、评分、分析与质量标记、历史审计、阅读备注、归档、实际阅读日期修订、回顾报告、手工资产及各次修订与来源、独立的研究记忆与全部版本、运行记录。没有遥测，网页脚本、样式和字体无需外部 CDN。

| 动作 | 数据去向 |
|---|---|
| 保存模型设置 | 地址、模型名、密钥和同意状态写入本地 SQLite；密钥只显示掩码 |
| 生成 / 修改研究草案 | 上传材料、历史意见和上一版草案发送给配置的模型端点 |
| 打开、浏览、阅读反馈 | 本地 SQLite |
| 同步采集 | 检索词发送到所选文献源，来源可见网络请求 |
| 处理论文 | 论文标题、摘要及任务所需研究方向/分类规则发送给配置的模型端点 |
| 备注与个人阅读反馈 | 本地保存；备注不传给模型 |
| 阅读事实概览、保存报告、收获／问题及修订 | 仅本地 SQLite；不调用模型或文献源 |
| 阅读回顾事实分享副本 | 浏览器下载；默认剥离私人反馈备注、资产标题与正文 |
| 阅读回顾个人完整副本 | 下载前显式勾选说明；全部历史 JSON 含反馈备注、日期声明、资产全部修订与来源、研究记忆的模型措辞、用户修订与决定，报告个人副本仅含该快照保存的正文 |
| 原归档导出 / 本地日报文件 | 用户选择的本地文件，可能包含备注 |
| 显式邮件投递 | 日报内容发送给已确认渠道中的收件人 |
| 阅读分析（模型辅助回顾） | **默认关闭**：未在「阅读分析」页授权前，阅读分析对模型的调用次数为零，即使模型连接已保存。授权独立于模型连接的知情同意，逐用途绑定端点与配置版本（任何设置保存都使旧授权失效）；材料清单与预览只读本地数据，预览令牌 15 分钟有效、一次性使用。授权类别默认不含备注等私人文本；用户补充摘录同样须单独授权。提交分析后按清单逐篇发送，每次发送前与结果落库前都重新核对授权与端点；候选含来源引用与逐字引文核对，伪造来源被剔除 |
| 分析候选 | 候选（收获/问题/方法）保存在本地 SQLite，标注结论性质与「待核对」状态；未经你确认不写入资产或长期画像。候选引用私人材料时登记在派生副本索引（只记 ID 与字段类别，不存原文），供撤回后定位 |
| 知识版回顾（跨文献专题综合） | **默认关闭且与阅读分析分开授权**：未在「知识版回顾」页为该用途授权前，综合调用为零。授权绑定端点、模型配置版本与材料类别；默认只含冻结元数据与历史模型概括，备注/结构化理由/摘录/资产内容/已核对候选须显式勾选。提交后发送清单内材料的版本锚点与最小必要文本，以及系统事实摘要；模型输出为待核对的专题/问题/候选联系；事实数字由系统统计，模型只收到紧凑摘要用于组织叙述，报告数值不采用模型输出 |
| 知识版报告与私人归纳 | 报告为本地 SQLite 冻结快照（`reading-insights.report/2`），包含事实统计、知识整理、材料清单哈希与实际覆盖。依赖私人材料的整条归纳登记为派生副本（`field_kind='synthesis'`），分享副本默认排除，个人副本须显式选择；资产删除预览会列出引用它的知识版报告 |
| 研究记忆（长期价值与近期兴趣候选） | **默认关闭且与分析、综合分开授权**：未在「研究记忆」页为该用途授权前，画像调用为零。授权绑定端点、模型配置版本与材料类别；默认只含冻结元数据与评分，结构化理由、备注、资产、摘录和已核对候选须显式勾选。结构化理由类别只发送理由码与有无标记，任务语境自由文本留在本地；系统只在本机判断是否集中于一个任务。模型只得到确定性证据分组与获准材料，输出只能是待核对的措辞，不能生成「已确认」状态 |
| 研究记忆与私人画像 | 条目保存在本地 SQLite，包含全部版本、证据组、用户修订、决定与来源链。默认不进入事实分享副本；条目个人导出和全部历史个人副本须显式选择。撤回授权、删除资产或摘录只把相关条目标为需复核并停止使用，不静默删除用户措辞；用户可在条目页删除全部本地版本，下载副本、备份和浏览器文件不自动收回 |

**授权边界**：在设置页保存模型配置即表示同意把以下内容发送给该服务——处理论文时发送标题、摘要及任务所需研究方向/分类规则（用于筛选、概括和评分）；生成草案时发送上传材料、历史意见和上一版草案；自动规划检索式时发送研究档案、已读评分历史和本次关注点。确认草案时写入的运行参数记录 `external_model_data=metadata_abstract`。同步不再逐次弹授权，但打开阅读队列不会自动联网。CLI 的真实模型调用仍要求显式 `--live`。

模型密钥从数据库或环境变量读取，日志中脱敏；页面只显示末四位掩码，密钥不进入运行报告、prompt 或归档。论文文本是不可信数据，不作为执行指令。阅读分析、知识版回顾与研究记忆在发送边界逐一核对用途授权、端点、配置版本、用户决定与材料类别，重试与修复同样受约束；撤回授权后立即停止新的发送。三类模型结果都不使用通用模型缓存（缓存键缺少端点与授权绑定）。知识版回顾的私人归纳按来源链继承私人类别：用户确认或合并候选不会自动把它变成可公开数据。研究记忆只用于回顾与资产整理，不写入研究档案，不进入检索、偏好评分、排序或入队。

外部服务如何保留请求由其政策决定。网关可能按有限次数重试瞬时错误；UI 失败后不会无限重新启动整条任务。

应用重启会将未完成的 UI Run 标记失败，保留已完成数据。阅读归档和历史日报保持不可变；设置页提供用户主动的工作区重置：需输入确认文字，先保存本地备份再清空业务数据，可选择是否保留模型连接。备份含模型配置与阅读数据，仅保存在本机数据目录的 backups/，文件权限为 0600。已有导出文件与备份保留。

导出文件含研究偏好或备注，分享前自行检查。更换设备前停止服务、复制完整数据目录并保管好；容器卷也需单独保存。详细配置见[配置指南](configuration.md)。

事实版阅读回顾只做统计和手工整理，不推断长期偏好；长期价值与近期兴趣只在你单独授权并手动提交研究记忆任务后由模型提出候选，且始终待你核对。生成事实报告默认只保存资产引用、状态和整理活动；显式勾选“包含手工资产正文副本”才在报告中另存原文。知识版回顾只使用单独授权清单内的材料，正文保存模型归纳、材料清单引用与实际覆盖；私人归纳的正文只在本机报告中，分享副本按来源链整条排除。报告和导出不会因后来修订而变化；授权模型分析不会自动获得清单之外的私人原文外发授权。

专题按活动发生时的资产来源版本筛选引用与可选正文，跨主题来源会有标记；至少一篇来源匹配才纳入。报告另外在本地保存范围、规范化请求及有效输入的版本／哈希清单，清单不另存备注或资产正文；知识版报告还保存本次综合的材料清单哈希、实际使用/缺失/省略计数与每条归纳的来源引用。旧报告上下文只恢复可核查的字段，未知不等于全部主题；补上下文不重写旧报告已有内容。

删除资产预览会列出曾保存正文副本的报告和相关研究记忆，可同时删除这些报告；研究记忆只追加需复核版本并保留你的措辞，未选择的私人副本仍保留，报告会说明来源已移除。重置会一并清空阅读日期、报告、资产及修订、来源和研究记忆，但重置备份、删除工作区的目录备份和浏览器下载文件仍含原数据。真正清除私人副本时还需自行处理这些本地文件。备份与恢复操作见 [FAQ](faq.md#阅读回顾如何备份与恢复)。
