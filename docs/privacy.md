# 隐私与数据流向

PaperSteward 面向本机单用户，默认绑定 `127.0.0.1`，没有登录系统。数据库保存研究方向、分类法、上传材料、论文元数据和摘要、评分、分析与质量标记、历史审计、阅读备注、归档、实际阅读日期修订、回顾报告、手工资产及各次修订与来源、运行记录。没有遥测，网页脚本、样式和字体无需外部 CDN。

| 动作 | 数据去向 |
|---|---|
| 保存模型设置 | 地址、模型名、密钥和同意状态写入本地 SQLite；密钥只显示掩码 |
| 生成 / 修改研究草案 | 上传材料、历史意见和上一版草案发送给配置的模型端点 |
| 打开、浏览、阅读反馈 | 本地 SQLite |
| 同步采集 | 检索词发送到所选文献源，来源可见网络请求 |
| 处理论文 | 论文标题、摘要及任务所需研究方向/分类规则发送给配置的模型端点 |
| 备注与个人阅读反馈 | 本地保存；备注不传给模型 |
| 阅读事实概览、保存报告、收获／问题及修订 | 仅本地 SQLite；不调用模型或文献源 |
| 阅读回顾事实分享副本 | 浏览器下载；默认剥离私人反馈备注、资产标题与正文 |
| 阅读回顾个人完整副本 | 下载前显式勾选说明；全部历史 JSON 含反馈备注、日期声明及资产全部修订与来源，报告个人副本仅含该快照保存的正文 |
| 原归档导出 / 本地日报文件 | 用户选择的本地文件，可能包含备注 |
| 显式邮件投递 | 日报内容发送给已确认渠道中的收件人 |
| 阅读分析（模型辅助回顾） | **默认关闭**：未在「阅读分析」页授权前，阅读分析对模型的调用次数为零，即使模型连接已保存。授权独立于模型连接的知情同意，逐用途绑定端点与配置版本（任何设置保存都使旧授权失效）；材料清单与预览只读本地数据，预览令牌 15 分钟有效、一次性使用。授权类别默认不含备注等私人文本；用户补充摘录同样须单独授权 |

**授权边界**：在设置页保存模型配置即表示同意把以下内容发送给该服务——处理论文时发送标题、摘要及任务所需研究方向/分类规则（用于筛选、概括和评分）；生成草案时发送上传材料、历史意见和上一版草案；自动规划检索式时发送研究档案、已读评分历史和本次关注点。确认草案时写入的运行参数记录 `external_model_data=metadata_abstract`。同步不再逐次弹授权，但打开阅读队列不会自动联网。CLI 的真实模型调用仍要求显式 `--live`。

模型密钥从数据库或环境变量读取，日志中脱敏；页面只显示末四位掩码，密钥不进入运行报告、prompt 或归档。论文文本是不可信数据，不作为执行指令。阅读分析在发送边界逐一核对授权、端点、配置版本与材料类别，重试与修复同样受约束；撤回授权后立即停止新的发送。阅读分析结果不使用通用模型缓存（缓存键缺少端点与授权绑定）。

外部服务如何保留请求由其政策决定。网关可能按有限次数重试瞬时错误；UI 失败后不会无限重新启动整条任务。

应用重启会将未完成的 UI Run 标记失败，保留已完成数据。阅读归档和历史日报保持不可变；设置页提供用户主动的工作区重置：需输入确认文字，先保存本地备份再清空业务数据，可选择是否保留模型连接。备份含模型配置与阅读数据，仅保存在本机数据目录的 backups/，文件权限为 0600。已有导出文件与备份保留。

导出文件含研究偏好或备注，分享前自行检查。更换设备前停止服务、复制完整数据目录并保管好；容器卷也需单独保存。详细配置见[配置指南](configuration.md)。

阅读回顾第一阶段只做事实回顾和手工整理，不推断长期偏好。生成报告默认只保存资产引用、状态和整理活动；显式勾选“包含手工资产正文副本”才在报告中另存原文。报告和导出不会因后来修订而变化，也不会因为将来启用模型分析就自动获得私人原文外发授权。

专题按活动发生时的资产来源版本筛选引用与可选正文，跨主题来源会有标记；至少一篇来源匹配才纳入。报告另外在本地保存范围、规范化请求及有效输入的版本／哈希清单，清单不另存备注或资产正文。旧报告上下文只恢复可核查的字段，未知不等于全部主题；补上下文不重写旧报告已有内容。

删除资产预览会列出曾保存正文副本的报告，可同时删除这些报告；未选择的私人副本仍保留，报告会说明来源已移除。重置会一并清空阅读日期、报告、资产及修订、来源，但重置备份、删除工作区的目录备份和浏览器下载文件仍含原数据。真正清除私人副本时还需自行处理这些本地文件。备份与恢复操作见 [FAQ](faq.md#阅读回顾如何备份与恢复)。
